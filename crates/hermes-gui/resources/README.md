# GUI bundle resources

## `markitdown-sidecar/`

Generated by:

```bash
# repo root
scripts/prepare-markitdown-bundle.sh
```

Contains a self-contained MarkItDown install: `python/` (vendored,
relocatable interpreter), `site-packages/`, and the `markitdown` wrapper. Packed
into the app via the `bundle.resources` entries in `tauri.macos.conf.json` /
`tauri.windows.conf.json`.

Nothing in the tree may reference the build machine: a venv would symlink
`bin/python` to an absolute path in the builder's uv cache, so we vendor the
interpreter and drive it with `PYTHONPATH` instead.

Do not commit the generated tree (see root `.gitignore`). Rebuild on each
release machine (`scripts/prepare-markitdown-bundle.sh`).

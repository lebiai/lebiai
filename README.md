# 乐彼AI（lebi-AI）

> **越用越像你的手感。**
> 接得住你的想法，推得动你的事，必要时敢顶你——第二次更准。

乐彼AI 是跑在你电脑上的**工作搭子**：懂你怎么想、怎么干活，陪你一起把事做成；有共鸣也有交锋；经你批准后沉淀你的偏好、标准和经验，所以**越用越贴**。

它不是闲聊玩具，也不是讨好机器——**理解你不等于赞同你**，该顶你的时候它敢顶你。

## 它帮你做什么

主场是**工作**：谋划、表达、决策、复盘、把事推进。

- **谋划**：把「下周要干的事」排成优先级，把模糊的想法理成可执行的方案。
- **表达**：起草、改写、打磨你的文字，保留你的味道。
- **决策**：把利弊摊开，帮你想清楚再做选择。
- **复盘**：事后帮你把经验教训沉淀下来。
- **推进**：跟着你把事情一步步做完，而不是聊完就散。

## 为什么越用越像你的手感

- **它记得你**：你聊过的事、你的偏好和标准，都会在**你批准后**变成它对你的了解。
- **像为你定制**：建议基于你沉淀下来的经验，而不是通用话术。
- **第二次更顺**：同类的事情，做过一次后它就知道你的做法，越用越准。
- **你说了算**：它学到的每一条记忆、每一个技能，都要你确认；你不点头，它不记。

## 隐私：一切在你的电脑上

- 你的对话记录、记忆、技能**全部保存在你自己的电脑上**，本地明文文件，随时可看、可备份、可删除。
- 只有「对话」这一步，会把你的话发送给你选的模型服务商（比如 DeepSeek、Claude、GPT）来生成回复。
- 没有账号系统、不依赖云服务、不会未经你同意上传任何东西。

## 开始使用（三步）

1. **下载安装**：macOS 装 `.dmg`，Windows 装 `.exe`——首次打开按提示「仍要打开」放行一次即可。详细步骤见 [安装与首次使用](docs/install.md)。
2. **配置模型**：打开设置，选一个模型服务商（默认 DeepSeek，国内用户支付宝就能充值），粘贴你的 **API Key** 保存。不知道怎么拿 Key？设置页里有内嵌教程，图文版见 [获取 API Key 教程](docs/api-key-guide.md)。
3. **开始对话**：直接说「帮我把下周要干的事排个优先级」就行。保存后立即生效，无需重启。

> 桌面版当前支持 **macOS 与 Windows**；手机端与微信、飞书、Telegram 入口正在开发中。

## 常见问题

- **为什么一定要 API Key？** 乐彼AI 是本地应用，本身不提供模型；对话能力来自你选的模型服务商（类似「水电公司」），Key 就是你在那家服务商的凭证，只存在你本机。
- **选哪家服务商？** 国内用户建议从 **DeepSeek** 开始：便宜、支付宝/微信可充值。Claude、GPT 质量更高，但需要海外支付方式。
- **数据存在哪？怎么备份？** 数据都在你电脑上：macOS 在 `~/.lebi-ai/`，Windows 在 `%USERPROFILE%\.lebi-ai\`。备份整个文件夹即可。
- **换电脑怎么办？** 把数据文件夹拷到新电脑的相同位置，登录同一服务商即可。
- **怎么卸载？** 从「应用程序」或「控制面板」卸载应用；数据文件夹可一并删除（删除即永久清除）。

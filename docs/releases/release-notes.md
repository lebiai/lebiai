# 乐彼AI 1.3 发布说明

> **种类：** C 发布说明（非权威）。冲突以 [`../../PRODUCT_PRINCIPLES.md`](../../PRODUCT_PRINCIPLES.md) **P0 v0.11** 为准。
> 越用越像你的手感。接得住你的想法，推得动你的事，必要时敢顶你——第二次更准。

## 1.3 带来的

- **对话里丢文件，之后问得到**：把 Word / PDF 拖进对话，文件会自动留下，以后新开对话也能问「之前那份文件里的话」，回答会点出《标题》。
- **问「手头有哪些」**：会看到留下的材料名单卡片；材料页可以「先读一段」、丢掉、打开原件。
- **在办更顺**：过了期限的债会先问「还做吗」；记下 / 换期自己选日子；有些事可以标「等别人」或「拆开」，不会被默默吞掉。
- **设置里有使用手册**：不知道去哪配模型、怎么授权，打开 **设置 → 使用手册**，人话讲清楚。
- **长中文不再乱码**：修好了长回答里偶尔出现的 `���`。
- **应用内更新真正可用**：1.2 装上的用户，这次可以直接在 **设置 → 概览** 点「更新」，自动下载、安装并重启，不用自己找安装包。

其余能力与 1.2 相同：在办、回顾、试用授权、设置五页签、它记得的、文档导入、微信连接。

## 安装

- **macOS**：下载 `.dmg`，把 `lebi-AI` 拖入「应用程序」。首次若提示“来自身份不明的开发者”，右键图标 →「打开」→ 确认。
- **Windows**：下载 `-setup.exe`。若出现 SmartScreen，点「更多信息」→「仍要运行」。

详细步骤见 [安装与首次使用](../guide/install.md)。

## 隐私与数据

- 对话、记忆、技能、在办、回顾、留下的材料都在**你自己的电脑**上（macOS `~/.lebi-ai`，Windows `%USERPROFILE%\.lebi-ai`）。
- 只有你主动对话时，当次内容才会发给你选的模型服务商。
- 授权码在本机校验，不上传对话去换许可。
- 卸载/重装、在设置里更新，数据目录原样保留。

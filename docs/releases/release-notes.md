# 乐彼AI 1.2 发布说明

> **种类：** C 发布说明（非权威）。冲突以 [`../../PRODUCT_PRINCIPLES.md`](../../PRODUCT_PRINCIPLES.md) **P0 v0.11** 为准。
> 越用越像你的手感。接得住你的想法，推得动你的事，必要时敢顶你——第二次更准。

## 1.2 带来的

- **设置里能看见版本**：打开 **设置 → 概览**，状态卡最下面一行是当前版本。
- **以后不用自己找安装包**：这一版起内置更新器。再发新版本后，同一处会出现「更新」，点一下就会下载、安装并重启。数据还在本机目录，不会动。
- 第一次安装仍用下面的 `.dmg` / `-setup.exe`。

其余能力与 1.1 相同：在办、回顾、试用授权、设置五页签、它记得的、文档导入、微信连接。

## 安装

- **macOS**：下载 `.dmg`，把 `lebi-AI` 拖入「应用程序」。首次若提示“来自身份不明的开发者”，右键图标 →「打开」→ 确认。
- **Windows**：下载 `-setup.exe`。若出现 SmartScreen，点「更多信息」→「仍要运行」。

详细步骤见 [安装与首次使用](../guide/install.md)。

## 隐私与数据

- 对话、记忆、技能、在办、回顾都在**你自己的电脑**上（macOS `~/.lebi-ai`，Windows `%USERPROFILE%\.lebi-ai`）。
- 只有你主动对话时，当次内容才会发给你选的模型服务商。
- 授权码在本机校验，不上传对话去换许可。
- 卸载/重装、在设置里更新，数据目录原样保留。

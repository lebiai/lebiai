# 乐彼AI 1.4 发布说明

> **种类：** C 发布说明（非权威）。冲突以 [`../../PRODUCT_PRINCIPLES.md`](../../PRODUCT_PRINCIPLES.md) **P0 v0.11** 为准。
> 越用越像你的手感。接得住你的想法，推得动你的事，必要时敢顶你——第二次更准。

## 1.4 带来的：你的 AI 团队

**侧栏不再是空白对话，是你的团队。** 每个人物是一个固定工位：他有名字、有一句「他是谁」，
有一块只属于他的活，也有一份只属于他的专业记忆。

- **工位**：情报王海燕（采当天情报）、林碳小谢（林碳的专家和记者）、具身智能小金（具身智能）、
  编辑雨天（审稿）、主播小雨（口播稿），加上自带的工具人李现在、资料员小文、大导演。
  **开通哪几个由你输入的那张授权码决定**——码里点名了谁，侧栏就出现谁。
- **一顶帽子，不是第二个人**：越界的活他会明确说不接，并**指给真有的那个工位**——
  指的名字你侧栏里找得到。
- **自由对话暂时下线**：原来那个「什么都接」的搭子小乐撤了。他谁都接、也就谁都拦不住，
  实测里最容易替别的工位下结论。每个工位现在都必须拦得住、指得清。
- **打开就是一句问候**：不再自动替你开一段对话，点左边哪个人，就跟哪个人干活。
- **记忆各归各的**：在林碳小谢那儿教的林碳口径，去具身智能小金那儿问不出来；
  关于你**自己**的偏好（比如交付一律用 Word 放桌面）所有工位都遵守。

## 1.4 同时带来的

- **记忆更清楚**：散落的记忆会按**主题**收成卡（「林碳报告口径」这类），不再是一槽一条往下塞；
  列表按时间倒序、分页，一页 10 条。
- **我的材料分得开了**：「我带来的」和「我产出的」两个页签，各自按时间倒序分页；不再混着罗列，
  也不再显示 `.py` 这类代码文件。
- **产出按天归位**：新产出的文件落在 `outputs/<日期>/` 里，并且会出现在「我的材料 → 我产出的」。
- **过程安静了**：失败不再刷一排红叉，改成一句话说清；一次任务的过程收成一条，不再铺满屏幕。
- **要你点的少了**：该松的授权放宽、该记住的记住，常见动作不再反复打断你。
- **安全**：产品密钥一律不进工具可读面。
- **修好的**：窗口关闭键一定关得掉；新建的技能当场就能用，不用重启 App；「它记得的」标题不再折行。

## 这一版明确没做的

- **工位侧栏还不能自己增删改**——名单和设定由产品方定。试用期只显示自带的三个人物。
- **越界指路还是纯文字**，还没有「一键切过去」的按钮（你看到名字，需要自己点侧栏）。
- **输入框提示语还没跟着人物变**。
- 技能面收窄目前只对「工具人李现在 / 大导演」打开，其余工位等绑定表定下来再收。

## 安装

- **macOS**：下载 `.dmg`，把 `lebi-AI` 拖入「应用程序」。首次若提示“来自身份不明的开发者”，右键图标 →「打开」→ 确认。
- **Windows**：下载 `-setup.exe`。若出现 SmartScreen，点「更多信息」→「仍要运行」。

详细步骤见 [安装与首次使用](../guide/install.md)。

## 隐私与数据

- 对话、记忆、技能、在办、回顾、留下的材料都在**你自己的电脑**上（macOS `~/.lebi-ai`，Windows `%USERPROFILE%\.lebi-ai`）。
- 只有你主动对话时，当次内容才会发给你选的模型服务商。
- 授权码在本机校验，不上传对话去换许可。
- 卸载/重装、在设置里更新，数据目录原样保留。

## 从 1.3 升上来

装过 1.3 的，在 **设置 → 概览** 点「更新」即可；也可以在下面的安装包里选对应平台重新安装，
数据不受影响。旧会话文件一条没删，只是侧栏不再列「最近对话」。

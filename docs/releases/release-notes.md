# 乐彼AI 1.1 发布说明

> **种类：** C 发布说明（非权威）。冲突以 [`../../PRODUCT_PRINCIPLES.md`](../../PRODUCT_PRINCIPLES.md) **P0 v0.11** 为准。
> 越用越像你的手感。接得住你的想法，推得动你的事，必要时敢顶你——第二次更准。

## 1.1 带来的

- **在办**：停下来还欠的交差，记下来必须有「哪天前」。过了会问还做不做；还做就要换新期。改、做完、丢掉不用悬停。
- **回顾**：按你选的日子（周五 / 周六 / 周一，默认不问）把这段日子蒸成周报底稿——干了什么、能交的文件、还欠。不是聊天摘要。
- **试用与授权**：首次打开起算 3 天试用。到期后对话等主能力锁定，把授权码贴进「设置 → 更多 → 软件授权」即可。本机验签，不绑机器、不登录账号。购买 / 续期加微信 **iodine001**（站外完成）。
- **设置更好走**：五个页签——概览 / 对话 / 外观 / 连接 / 更多。外观改完即生效；模型与安全相关点保存。记忆与进化、上下文与工具可以在「更多」里改。
- **它记得的**：记忆和技能在一处。有待审时，侧栏数字点进去就是待审；点「它记得的」四个字仍进记忆/做法。
- **越用越贴**：离开对话后会安静提炼候选，须你点头才落盘。同类事一条生效规则。
- **文档导入**：macOS 与 Windows 安装包都带转换器，Word / PDF / Excel 可直接拖进对话。
- **微信**：可在设置里扫码连接，记录只看不发，和桌面对话进同一份数据。

## 安装

- **macOS**：下载 `.dmg`，把 `lebi-AI` 拖入「应用程序」。首次若提示“来自身份不明的开发者”，右键图标 →「打开」→ 确认。
- **Windows**：下载 `-setup.exe`。若出现 SmartScreen，点「更多信息」→「仍要运行」。

详细步骤见 [安装与首次使用](../guide/install.md)。

## 隐私与数据

- 对话、记忆、技能、在办、回顾都在**你自己的电脑**上（macOS `~/.lebi-ai`，Windows `%USERPROFILE%\.lebi-ai`）。
- 只有你主动对话时，当次内容才会发给你选的模型服务商。
- 授权码在本机校验，不上传对话去换许可。
- 卸载/重装、升级安装包，数据目录原样保留。

## 用户怎么走

1. 打开仍是对话。  
2. 丢进 Word / PDF：当次能用，并**自动留下**。**不问留不留。** 第一次留下提一句「下次直接问就行 · 撤销」；之后静默，去「我的材料」丢掉。换成新版或读不出字时仍提一句。  
3. 下次直接问材料里的事，不必打开「我的材料」。答里一句「按你那份《xx》」。无关问题不提材料。  
4. 「它记得的 → 我的材料」：列表、打开原件、**丢掉**（确认一次）。也可在此加入文件。

## 不做什么

不预装行业/公共知识；不把材料写入记忆；IM 不检索；`hermes ask` 不检索；开口不读每一份原件。

## 0. 一句话

在办从侧栏搬走，挂在对话右上角；点开是右侧抽屉。  
抽屉里两页：**还欠的**（在办）和**这段日子做成了什么**（回顾）。  
定时只做一件事：到了**你定的那天**打开软件，问一句要不要回顾——不长循环任务，关着 App 也不开火。星期几不替你猜（双休的人周五就能收；周日不该默认盯电脑）。

强化：好看/好走（在办不再抢会话列表）；① 跨次看见还欠的；⑤ 一段日子能复盘。

## 1. 已拍板决策

| # | 议题 | 结论 |
|---|------|------|
| 1 | 在办摆哪 | **对话顶栏右侧一颗按钮** → 从对话面板右侧滑出抽屉。侧栏在办块**删除**。 |
| 2 | 抽屉里几页 | 两页：**在办** / **回顾**。不要第三页「定时任务」。 |
| 3 | 默认打开哪页 | **有开着的债 → 在办**。否则：若是回顾日且本区间还没蒸 → **回顾**。再否则在办（空态）。 |
| 4 | 定时任务 | **不做**日/周/月循环待办。节奏只服务回顾。 |
| 5 | 回顾节奏 | **默认关。** 用户自己选每周的星期几开口问一句。可关。无按日催，v1 无按月。**禁止默认周日。** 回顾页给快捷：周五 / 周六 / 周一 / 不要问。 |
| 6 | 回顾区间 | 默认 **到今天为止的本周**（本地周一起 → 现在）。抽屉可改起止再蒸，可存成默认（本周 / 最近 7 天 / 上次自定义）。节奏日也用这个默认区间——周五问则正好是周一到周五。 |
| 7 | 回顾产出 | 一份人能读的明文回顾，不是记忆、不是技能。人点头才可把「还欠」收成在办，或把 0–2 条规则推进化待审。 |
| 8 | 何时蒸 | 人点「回顾」或答应进门那一句才蒸。**关着 App 不跑。** 无系统通知。 |
| 9 | 和离开蒸馏 | 并行、不抢。离开仍只抽规则进待审；回顾是交差账。 |

## 2. 用户怎么走

### 2.1 打开在办（主次仍是对话）

1. 人在对话里。顶栏右侧看见按钮「在办」；有开着的债则带数字（待收下不进主数字，可用浅点）。  
2. 点按钮 → 对话右侧滑出抽屉，会话列表不动。  
3. 再点按钮或点抽屉外的对话区 → 关上。Esc 关抽屉（不关工具确认）。  
4. 窄窗：抽屉盖住对话右侧，仍可关。

### 2.2 抽屉 · 在办页

对象与操作仍服从 [`zaiban.md`](./zaiban.md) §3–§6：记、收下、勾完、丢掉、改标题、等、拆、并、回源会话、开始做先问完成算什么。

- **空：** 「对话里说：帮我记下周五交方案。」+「记」  
- **有：** 待收下在上，开着的在下；挤了说「先清再加」。  
- 点一条标题 = 开始做（预填仍在对话输入框）。抽屉可保持开着。

### 2.3 抽屉 · 回顾页

1. 看见默认区间（如「本周 8/10–8/14」）和主按钮 **回顾这段**。  
2. 可改起止日期；「设为默认」只记区间规则（本周 / 最近 7 天 / 自定义上次用的），不另开产品。  
3. **每周哪天问我：** 未设过则在回顾页先选一天（周五 / 周六 / 周一 / 其它星期 / 不要问）。设过可随时改。不弹系统设置迷宫。  
4. 点回顾 → 加载（有结束感）。成功：交差账留在本页（做成了什么 / 产出 / 还欠）+ 一句「这段交差账已记下」。  
5. 再开抽屉默认停在**过往目录**（不是正文）。点一条才进入读账。蒸完刚写好的那份会立刻打开读账。  
6. **读账独占抽屉**：目录、节奏、设区间都让开。左上角 **收起** 回到目录。Esc 仍关整个抽屉。  
7. 正文按文章排：日期作题、一两句总述、做成了什么 / 产出 / 还欠分节留白。禁止把 Markdown 原文糊进窄栏。  
8. 蒸和节奏只在目录页。读账底栏只有「再看一次」。同一区间再蒸覆盖上一份。  
9. 人可以：点过往读、收起、再看一次、从还欠回到在办。规则候选若有，走现有进化待审（须再点头）。  
10. 失败：人话「没蒸成，过会儿再试」；区间里没有会话则空态「这段日子没有对话」。

**回顾长什么样（给模型与展示的结构，不是用户要填的表）：**

- 这一段在干什么（一两句）  
- 做成了什么（交差，不是过程流水）  
- 产出（真实路径；没有就不写）  
- 还欠什么（对照开着的在办，不发明债）

禁止：把工具名、沙箱、心情当产出；禁止假装记得区间外的事。

### 2.4 回顾节奏（进门那一句）

**未设过星期：** 不进门追问。等人第一次打开「回顾」页，用一排轻选项问「每周哪天问你一句？」——**周五**（双休收工前）放第一个，另有周六、周一、其它、不要问。选完即记。不预勾周日。

**已设星期：** 仅当今天就是那天 ∧ 本默认区间还没有成功回顾 ∧ 主窗口到前台。

对话里一条递回（与在办 Cue 同一家族，不同时堆两条——见 §3）：

> 要回顾这段日子吗？

主按钮 **回顾** → 开抽屉并停在回顾页（可用当前默认区间直接蒸）。次操作关掉，当天不再问。

不是模态，不挡对话。关着软件等到点也不会自己蒸。

### 2.5 授权

看在办、看旧回顾、改节奏与默认区间：不走对话门禁。  
蒸一次回顾：走 `can_use_main`（要用模型）。锁了就说明「试用/授权到期后才能回顾」。

## 3. 看起来怎么样

- 按钮：对话顶栏右侧，克制，不像工具条。有债才强调数字。  
- 抽屉：现有色、圆角、留白；宽约对话区 36–40%，最小约 280px。标题区：在办 | 回顾 两个页签。  
- 进门 Cue 仍一事一点。优先级（高→低）：工具近义确认 → 待收下 → **回顾日邀请** → 近义并 → 过期在办 → 空会话「还有 N 件」。同时只一条。  
- 回顾正文是文章，不是看板、不是日历。

### 空 / 载 / 错

| 态 | 在办页 | 回顾页 |
|----|--------|--------|
| 空 | 一句教怎么记 | 「这段日子没有对话」+ 改区间 |
| 载 | 列表一行骨架 | 按钮进入「正在回顾…」至多数十秒，可关抽屉（蒸在后台，好了再看） |
| 错 | 「没读出来」 | 「没蒸成」 |

### 不出现

- 会话侧栏里的在办块  
- 顶栏第四项、它记得的第三 Tab  
- 循环任务列表、日历、系统通知  
- 离开会话大弹窗审回顾  
- 关着 App 的定时开火  
- 出厂就每周日催回顾

## 4. 架构（实现须服从）

- **在办数据**仍是 `data_root()/commitments.json`，对象不改。  
- **回顾落盘** `data_root()/reviews/YYYY-MM-DD_<from>_<to>.md`（明文）。索引可用同目录一份 `reviews.json` 记：区间、做成时刻、路径、是否本默认区间。  
- **节奏与默认区间**写在 `config.toml` `[review]`：`weekday = 0` 表示未设/关闭（**出厂默认**）；`1`–`7` 为周一至周日。`default_span = "this_week"` | `"last_7_days"`。禁止把 `weekday` 出厂设成 7。  
- **蒸：** 读区间内会话 JSONL（`sessions/`，含渠道记录只读）+ 该区间勾完/仍开的在办 + 会话里真实写过的路径。一次 LLM，结构化短文。禁止塞进 `ReflectionOutput`。规则候选若有，走现有 `pending-review`。  
- **关着不跑：** 无 launchd/计划任务。只在 GUI 到前台时检查 §2.4。  
- **入口：** v1 仅桌面 GUI。CLI 可后接同一份 reviews（非默认）。IM / Flutter 不做写。  
- **删旧：** 实现时删除侧栏 `ZaibanBlock` 及只为它存在的样式；对话 Cue、工具、store 保留。

- [ ] 改区间能蒸；空区间人话空态

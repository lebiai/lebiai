## 0. 用户价值

设置是「把乐彼AI 调到能好好用」的控制台：主任务清晰、保存规则可预期、UI 同构、低频风险项不抢戏。

## 2. 顶层导航（5 Tab）

| 顺序 | Tab 名（中文） | 英文 key 建议 | 用户一句话 |
|------|----------------|---------------|------------|
| 1（默认） | **概览** | `overview` | 现在能不能好好用 |
| 2 | **对话** | `dialogue` / `model` | 连哪个模型、Key 对不对 |
| 3 | **外观** | `appearance` | 语言、主题、怎么叫我 |
| 4 | **连接** | `connections` | 微信等渠道 |
| 5 | **更多** | `more` | 授权、数据、专家选项 |

**废弃名：**「账户」（无账号体系时名不副实）。

**深链：**

| 来源 | 目标 |
|------|------|
| 无 API Key 发送拦截 | Tab「对话」 |
| 侧栏授权提示 / 临期 CTA | Tab「更多」→ 锚定授权块；或概览「去续期」 |
| 概览快捷「去配置模型」 | Tab「对话」 |
| 概览「连接微信」 | Tab「连接」 |

## 3. 各 Tab 内容

### 3.1 概览（默认 · 主）

**一块状态总览，不是又一张设置表单。**

必含：

1. 称呼问候（轻）  
2. **对话就绪状态**：已配置 Key / 请配置 API Key（主）  
3. **使用期一行摘要**：试用剩余 / 已授权至某日 / 已过期（点「去续期」→ 更多·授权）  
4. **微信一行摘要**：未连接 / 监听中…（点进「连接」）  

行为：

- 无 Key：**唯一强 CTA** = 去配置模型  
- 授权临期：次强 CTA = 去续期  
- 都正常：无恐吓，可弱展示  

可含 2～3 条快捷行（称呼 / 语言 / 主题）跳到「外观」。

**禁止：** 概览内授权大输入框、微信扫码、数据迁移、工具权限编辑。

### 3.2 对话（原模型服务）

1. 一句话说明：选服务商 → 填 Key → 可对话  
2. 服务商选择  
3. Key 状态（已配置绿/中性条 + 更换/清除；未配置输入 + 帮助）  
4. **高级参数**默认折叠：模型名 / max tokens / base URL，hint「一般不用改」  
5. **显式保存**（见 §4）

### 3.3 外观

| 项 | 保存 |
|----|------|
| 称呼 | **即时**（失焦或确认后写盘） |
| 语言 | **即时** |
| 主题 | **即时** |
| 保留思考过程 | **即时** |

统一「设置行」：左标签、右控件、底 hint。  
本页**无**大主「保存」按钮（或仅在有未用完草稿时出现——优先即时无草稿）。

### 3.4 连接

- 仅渠道：当前 **微信**（状态机可沿用，样式向设置行 + 状态徽章收敛）  
- 页顶一句人话：连上后可在手机微信找乐彼AI  
- 不塞授权、不塞数据目录  

### 3.5 更多

**固定顺序手风琴 / 二级区块：**

1. **软件授权**（状态为主；贴码条件展开，逻辑同 `license-ux` + 已授权收起输入）  
2. **数据位置**（路径、更改、风险、恢复默认；破坏性确认）  
3. **记忆与进化**（min turns、自动接受记忆——危险默认需副文案）  
4. **上下文与工具**（token 上限、allow/deny）  
5. **工作区**（只读说明）  
6. **欢迎仪式**（最弱、最底）  

专家项：**显式保存**（与对话页同一套按钮语义，或本页底栏「保存高级设置」）。

## 4. 保存策略（拍板 3A）

| 类型 | 策略 | 范围示例 |
|------|------|----------|
| 外观 / 偏好开关 | **即时生效并落盘** | 语言、主题、称呼、persistThinking |
| 对话与安全 | **显式「保存」** | API Key、模型高级参数、反思、权限、上下文上限 |
| 破坏性 | **确认弹层** | 数据迁移、断微信、清 Key |

页级固定说明（对话 / 更多可见一句即可）：

> 外观类改完即生效；对话与安全相关项请点保存。

---

## 5. UI 统一原则

1. **状态徽章**共用三语义：成功 / 警告 / 危险（Key、授权、微信一致）  
2. **设置行**同构；少「每块一张说明书」  
3. 非概览 Tab：轻页标题，**不再**重复大问候卡+当前模型（概览已承担状态）  
4. 密度：主路径留白优先；高级默认折叠  
5. 加载 / 错误 / 已保存：单一顶栏反馈槽，不互相抢

## 7. 明确不做什么

- 不增加第 6 个顶层 Tab  
- 设置内不做支付  
- 不做账号登录 / 云同步 UI  
- 不把 MCP / 技能 / 记忆管理塞进设置  
- 不恢复侧栏独占装饰电池栏（侧栏仅轻提示 + 深链）  

---

## 8. 成功标准（验收）

1. 新用户从默认**概览** ≤1 分钟理解缺 Key，并到达对话页配好。  
2. 改语言/主题/称呼无需找「保存」。  
3. 续期：概览或侧栏 ≤2 步到「更多·授权」贴码。  
4. 用户能用一句话复述保存规则（§4 文案）。  
5. 无「账户」指代无账号；授权 vs API Key 不混称。

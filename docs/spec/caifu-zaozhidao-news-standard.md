# 第一部分 · 判稿原则（人与 Agent 共用）

## 1. 定位

**《财富早知道》是财经栏目，读者是投资人，主题是钱。**
不是新闻联播，不是时事观察，不是评论节目。

**选稿的唯一起点：这条消息对读者的钱意味着什么。**
"重要但跟钱无关"的消息，无论多大，都不进版。

**已锁定的排除项（不再讨论）**

| 排除项 | 处理 |
|---|---|
| 国家主要元首及领导人活动（出访、会见、讲话、考察、主持会议） | 不收 |
| 会议与外交的程序性消息（召开了、定档了、"回应了/表示/指出"而无条款、无金额、无价格） | 不收 |
| 政务与民生（试点成效、农村项目、地方活动、部委工作表态） | 不收 |
| 海外主体、人物命运、民生生活 | 不收 |
| 图片形态、音频形态 | 不收 |
| 碳中和 | 不单列，并入产业动态 |
| 财经日历 | 不做 |

## 2. 三个栏目（唯一的分类框架）

| 栏目 | 装什么 |
|---|---|
| **宏观** | 政策、监管发文、全局经济与金融数据 |
| **产业动态** | 某个产业的数据与趋势（含绿色低碳、循环经济类） |
| **资本市场** | 公司事件、全市场价格与资金、上市公司公告 |

**每期结构（12 期实测）**

| 栏目 | 块数 | 每期条数 | 中位 |
|---|---|---|---|
| 宏观 | 恒定 1 块 | 2—7 | 3 |
| 产业动态 | 1—2 块（行业 + 碳中和，碳中和 7/12 期出现） | 1—5 | 4 |
| 资本市场 | 恒定 2 块（公司块 + 市场块各 1） | 7—13 | 10.5 |
| 主稿合计 | 4—5 块 | **12—23** | 16.5 |
| 重要公告 | 独立输出（9/12 期有） | 12—34 | 26 |

> **配额是目标不是底线。** 某栏这期没料就写少些，**绝不允许用政治消息或旧闻凑数**。

## 3. 第一道门：财经属性门（最关键的一步）

逐条问一句话，答不出来就弃：

> **这条消息，改变了哪个价格、哪家公司的成本或盈利、哪条规则？变化前后差多少？**

**一句话验收**：把这条消息念给一个满仓的投资人听，**他会去动仓位吗**？不会，就弃。

| 过得去（能落到钱上） | 过不去（再大也不进版） |
|---|---|
| 六大行中期分红比例升至 31% → 银行股股东拿到的现金变多了 | 中美经贸磋商在纽约举行（无条款、无结果、无数字） |
| 骨科集采平均降价 84% → 相关耗材企业收入下降 | 政治局决定五中全会 10 月 26—29 日召开（议程信息，无政策条款） |
| 上期所铜仓单减 4347 吨 → 铜的现货紧张度变化 | 外交部就稀土出口管制、中日议题表态 |
| 沪指成交 9467 亿元、超百股涨停 → 市场状态与仓位判断 | 中西部农村"快递进村"试点取得阶段性成效 |
| 集运欧洲航线运价跌 10.2% → 外贸与航运链景气度 | 国家粮食和物资储备局表态"粮食安全有可靠保障" |

**三类必砍的政治／政务消息**

| 类型 | 特征词 | 例子 |
|---|---|---|
| 元首与领导人活动 | 出访、会见、讲话、考察、主持 | 习近平将对美国进行国事访问 |
| 会议与外交的程序性消息 | 召开、决定…召开、举行、回应、表示、指出 | 政治局会议决定五中全会定档；中美经贸磋商在纽约举行 |
| 政务与民生 | 试点成效、农村、地方、部委表态 | 快递进村试点；粮食安全表态 |

**唯一例外：听说"回应／辟谣"能不能留，看谁在说。**

| 谁在说 | 判 | 例 |
|---|---|---|
| **上市公司说自己的事** | 留 | 腾讯回应入股传闻不实；万科回应"高管被边控"；海天味业第三次回应添加剂风波 |
| **未上市公司说自己的事** | 弃 | 智谱回应 ZCode 隐私争议——没有股价，改变不了任何可交易资产 |
| **政府部门谈政治外交议题** | 弃 | 外交部回应稀土出口管制；外交部回应中美峰会议题 |

> **前提条件：这家公司必须有可交易标的。** 样本里 6 例"回应"全部是上市公司。没有股价的公司，回应再漂亮也过不了第一道门。

## 4. 第二道门：三具体门

| 检查项 | 判定口径 | 通过例 | 不通过例 |
|---|---|---|---|
| **具体主体** | 有名字。机构名、公司名都算 | 万科、派能科技、国常会、证监会 | "某机构""业内人士""有消息称" |
| **具体数字** | 金额、幅度、规模、时间，至少一个 | 虚增营收 2.26 亿占 39.61%；740 元/克；25.36 万人 | "大幅""显著""明显""或将" |
| **具体后果** | 发生了什么不可逆的事 | 被留置、被问询、破产、罚 200 万、爆仓 | "将积极推进""值得关注""有待观察" |

**三缺一即出局。** 若只是"够具体但不够大"，不扔，降到**上市公司公告池**。

**机构类事件的数字口径**：会议、定档类消息常常没有数字，以「**是否明确了时间／议程／结果**」代替"数字"这一项。明确了放行，只是"召开了"降级。
（此条只适用于**已经通过财经属性门**的机构消息，例如"国常会决定对个人养老金实行个税优惠"。）

## 5. 第三道门：归栏判定

**宏观**
- 政策决定：国常会决定对个人养老金实行个税优惠
- 监管发文：证监会修订《上市公司股份回购规则》
- 全局数据：前三季度 GDP 870269 亿元，同比增长 3%
- 中央集采：骨科脊柱类耗材集采，平均降价 84%

**产业动态**
- 行业产销数据：4 月全社会用电量 7412 亿千瓦时，同比 +7.0%
- 行业标准与规划：《能源碳达峰碳中和标准化提升行动计划》
- 行业格局变化：乘用车降价规模已超 2023 年全年六成
- 绿色低碳类：绿色贷款余额 19.55 万亿；绿色债券存量 1.2 万亿
- 市场规模预测：语言大模型市场规模 2027 年有望达 600 亿元

**资本市场**
- 公司事件：立案、处罚、留置、破产、并购、业绩、回购、减持、辟谣
- 市场价格：指数涨跌（有幅度，或破了关键位）
- 市场资金：北向／南向资金净额（含个股明细）、ETF 资金流、融资余额
- 市场产品：新股与打新、解禁、ETF、基金分红与募集、公募 REITs、ST 与退市、指数编制
- 上市公司公告：`公司名：一句话 + 数字` 的长尾收纳

**边界规则（三栏之间有重叠时，按这四条判）**

1. **政策 + 影响多家公司** → 归**宏观**（例：骨科集采平均降价 84%，进宏观，不进产业动态）
2. **单一公司 + 有系统性后果** → 仍归**资本市场**（例：300 亿券商易主，进资本市场）
3. **数据 + 覆盖全市场** → 归**资本市场**；**数据 + 只覆盖一个产业** → 归**产业动态**
4. **单一公司的数据，按"读起来像什么"判**：
   - 读起来是**产业指标**（订单储备、新签合同、开工率、产量、产能）→ 归**产业动态**
   - 属**公司治理与资本动作**（股权变更、并购、诉讼、冻结、立案、减持）→ 归**资本市场**

> 这条线的判法：**问它改的是"这家公司怎么经营"，还是"这家公司的股权和资本结构"。** 前者进产业动态，后者进资本市场。

> 归不进三个栏目里的任何一个 → **弃**。
> 历史栏目「焦点」不再单独保留（样本 12 期中出现 1 次），其条目按上述规则分别并入三栏目。
> **采集端预分的栏目一律视为参考，必须复检。** 实测 09-21 卷「宏观」栏下 21 条中有 5 条（约 24%）实为公司事件（如"观想科技拟以 4.82 亿元收购辽晶电子 60% 股权"），应归资本市场。归栏以本节规则为准，不以源栏目为准。

## 6. 定版前：相似复检

**版面上出现两条读起来像"同一件事"的新闻，读者的体感是内容不够。所以相似只留一条。**

判「相似」只需看两条，命中任一条就算：

| 判据 | 例 |
|---|---|
| **同一主体** | 中汽协 8 月乘用车数据；中汽协 1-8 月 MPV 数据 → 同一个发布方 |
| **同一子题材** | 中国电建"水"项目储备；中国建筑新签合同额 → 同属建筑装饰行业的订单类数据 |

**留哪条**：先看同日竞争排名；相同则**留事实更硬的那条**——已发生 > 计划中，已签 > 跟踪。

> 全版复检一定要通读一遍，**不要只看单条**——两条单独看都不错的新闻，放在一起就是重复。

**不适用去重的两处（别误伤）**

1. **上市公司公告池**：按定义就是同类长尾收纳，`A 公司担保 / B 公司担保` 不算重复。
2. **同一天内同类数据的不同方向**：如"欧洲航线跌 10.2%、美西航线涨 5.7%"是**一条**新闻里的两个方向，不拆。

# 第二部分 · 执行流程（Agent 规范）

## 7. 输入数据形态、状态与输出

### 7.1 输入源的真实格式

生产输入不是裸新闻流，而是采集端产出的**资讯卷**（例：`/Users/aodun/Documents/codeINDEx/test/workspace/outputs/2026-09-21/资讯-2026-09-21.md`）。实际结构：

```text
# 财富早知道 · 资讯卷｜窗口 2026-09-21 00:00 — 2026-09-21 19:30（北京时间）
采集：…｜允许名单内全量采集｜每条标信源层级（官方／主流／其他），栏内按原始发布时间倒序

## 宏观
【官方】新华财经｜2026-09-20 14:37｜
〈正文，一句话至一段〉｜
〈来源 URL〉

## 产业动态
## 资本市场
```

| 字段 | 说明 | 生产用途 |
|---|---|---|
| 栏目（`## 宏观／产业动态／资本市场`） | 采集端预分栏 | **仅作参考，必须按 §5 复检**（实测约 24% 归错） |
| 信源层级（`【官方／主流／其他】`） | 采集端标记，**站点属性**（按名单一一对照） | 只决定要不要交叉验证，**不进重要性、不进排序**，见 7.2 |
| 来源 | 允许名单内媒体名 | 只用于 `verification_confidence`，见 §9、7.3 |
| 时间戳 | 原始发布时刻 | 事件时间，用于窗口裁剪（§8） |
| 正文 | 一句话至一段 | 事实提取；缺失进 WAIT_VERIFY（§10） |
| URL | 原文链接 | 追溯与材料补全 |

输入量实测：**74—181 条/期**（09-20 卷 74 条、09-21 卷 181 条），主稿 12—20 条，压缩比约 **1:8—1:15**。

### 7.2 采集端信源层级的处理

采集端条目的第一字段是**信源层级** `【官方／主流／其他】`（2026-09-22 换版；旧的 `【A／B／C】`
标记**含义从未定义** —— 实测同一类证监会条目被标过 A、也被标过 C —— 已整块撤下）。它与
公告池的 A／B／C／D 分级是两个完全不同的体系，禁止互相套用。

- 层级是**站点属性**（这条从哪个站来的），按允许名单一一对照得出，不由模型自由裁量；口径同 §7.3 三级。
- **它只有一个作用**：决定这条**要不要再找一个来源**（「其他」必须有第二个独立来源）。
- **禁止**把 `【官方】` 当重要性、权威性或入选依据；层级**不进重要性、不进排序**——栏内一律按发布时间倒序。

### 7.3 信源可信度分层

`verification_confidence` 分三级，**只决定是否需要交叉验证，不影响重要性**：

| 层级 | 范围 | 处理 |
|---|---|---|
| 一级 · 官方 | 证监会、交易所、统计局、央行、部委官网，以及公司公告的正式披露渠道 | 可直接采信；核心数字仍须与正文对应 |
| 二级 · 主流媒体 | 新华财经、第一财经、证券日报、中国证券报、每日经济新闻、券商中国等 | 采信；与其他来源冲突时以一级为准 |
| 三级 · 其他 | 自媒体、商业科技媒体、未标注信源的转述 | 必须有第二个独立来源交叉验证，否则降 WAIT_VERIFY 或 DROP（见否决清单第 8 条） |

> 分层不改变"来源权威不得直接决定 KEEP"这条铁律（见 §23 禁止规则第 2、6 条）。

### 7.4 状态与输出

| 状态 | 含义 | 处理 |
|---|---|---|
| EXCLUDE | 当前产品明确排除 | 停止处理 |
| WAIT_VERIFY | 事实材料不足，无法可靠判断 | 补齐后重新处理（有截止条件，见 §10） |
| DROP | 完成判断但不进入最终内容池 | 停止处理 |
| CANDIDATE | 具有财经信息价值 | 继续聚类与竞争 |
| KEEP | 通过同日竞争 | 进入 MAIN_NEWS |
| HOT | 从 KEEP 中再次竞争产生 | 进入 HOT |

产出三类：**MAIN_NEWS**（主稿）、**ANNOUNCEMENTS**（公告池）、**HOT**（热点提示，即推送标题行）。

## 8. 时间窗（就一条：今天 00:00 → 采集时刻）

**默认时间窗 = `[今天 00:00, 采集时刻)`**，北京时间。

- **起点固定是今天 00:00**；**终点是按下采集的那一刻**（`date '+%Y-%m-%d %H:%M'`）—— 不是固定钟点，也不是自然日收尾。早上跑就采到早上，下午跑就采到下午。
- 早于今天 00:00、晚于采集时刻的条目一律丢弃。**昨天和更早的旧闻不许上卷。**
- 用户说「近 3 天」→ 窗口 = `[现在-72h, 现在)`，覆盖上面的默认值。
- 窗口写进**资讯卷卷首第一行**，下游按同一区间裁剪。
- 事件发生在窗口前、但在窗口内出现重大新进展的，按新进展时间进入，并与原事件建立 event_group。
- 持续事件只有在窗口内出现新增信息时才重新进入候选。
- 无法确认事件时间，进入 WAIT_VERIFY。

### 8.1 采集窗口 = 生产窗口

采集端与定调端用**同一个区间**：今天 00:00 → 采集时刻。

1. 采集窗口记为 `[S_start, S_end)`，生产窗口就是它本身。
2. **只保留落在窗口内的事件**；窗口外的条目一律丢弃，不得因为"卷里有"就采用。
3. 决策记录中必须写明本期实际采用的窗口区间。

## 9. 源级去重与事件级合并

**源级去重**：同一主体 + 同一事件 + 同一时间窗口 + 同一核心事实，只建立一个事件。不同来源全部保留在 `sources` 中，不得重复占用名额。
去重键字段：主体、事件（动作/变化/政策/数据/风险事实）、时间、核心事实（关键数字、动作、结果）。

`source_count` 与来源权威程度只用于 `verification_confidence`，**不增加新闻重要性**；不得因为来源多或来源权威而直接 KEEP。

**事件级合并**：以下链条必须合并为一个 event_group——
传闻 → 官方回应｜调查 → 处罚｜收购 → 终止｜收购 → 诉讼｜减持 → 官方回应｜重大事项 → 市场反应｜政策发布 → 后续官方解释。

> **event_group 是竞争的基本单位，一个事件组原则上只产生一个主稿事件。**

## 10. 正文完整性与 WAIT_VERIFY

以下情形进入 WAIT_VERIFY：只有标题没有正文；核心数字缺失且该数字决定重要性；主体不明确；来源不明且无法交叉验证；事件时间无法确认；标题与正文事实不一致。

- **禁止根据标题自行补全事实。** 补齐材料后必须重新运行完整筛选流程。
- **截止条件**：到采集时刻仍未补齐的，自动转 DROP，并记录缺失字段与原因。禁止无限期挂起。

## 11. 排除规则（当前产品口径）

| 对象 | 处理 | 执行规则 |
|---|---|---|
| 国家主要元首及领导人活动 | EXCLUDE | 出访、会见、讲话、考察、主持会议 |
| 会议与外交的程序性消息 | EXCLUDE | 无条款、无金额、无价格的"召开／举行／表示／指出" |
| 政务与民生 | EXCLUDE | 试点成效、农村项目、地方活动、部委工作表态 |
| 民生 | EXCLUDE | 不进入财经主稿 |
| 海外要闻 | EXCLUDE | 当前产品主动排除；**不是**历史样本反推结论（历史样本每期都有海外板块） |
| 人物 | 默认 EXCLUDE | 只有人物行为构成明确公司／资本市场／监管／经营事件时，转入对应事件类型 |
| 财经日历 | EXCLUDE | 不进入新闻事件竞争 |

**人物事件转化规则**：上市公司实控人、董事长等发生被留置、调查、控制权变化或重大经营影响时，人物只是事件主体，事件本身进入公司／监管／资本运作等类型（样本印证：派能科技董事长被立案调查、留置，收在"公司"块而非"人物"块）。

## 12. 事件类型

| 代码 | 事件类型 | 代码 | 事件类型 |
|---|---|---|---|
| POLICY | 重大政策 | RUMOR_RESPONSE | 传闻／澄清／官方回应 |
| MACRO_DATA | 重大经济／宏观数据 | INDUSTRY | 产业／行业重大变化 |
| EARNINGS | 业绩／业绩预告 | SUPPLY_CHAIN | 供应链重大变化 |
| EARNINGS_REVERSAL | 业绩反转 | FINANCIAL_RISK | 金融风险 |
| MARKET | 市场异常／市场结构变化 | FINANCIAL_SECURITY | 金融安全事件 |
| REGULATORY_RISK | 监管／司法／合规风险 | INVESTOR_INFORMATION | 投资者直接可用信息 |
| CAPITAL_OPERATION | 重大资本运作 | CONSUMPTION_MARKET | 消费市场异常 |
| MAJOR_OPERATION | 重大经营动作 | PRIMARY_MARKET_FINANCING | 一级市场融资 |

> **碳中和相关产业事件统一使用 INDUSTRY 类型，不单列 CARBON**——碳中和只是产业动态下的一个题材。

## 13. 事件强度

| 等级 | 定义 | 默认处理 |
|---|---|---|
| S0 | 日常信息，信息增量和影响均低 | DROP |
| S1 | 一般财经信息，有一定价值但不足以进入主稿 | CANDIDATE 后竞争 |
| S2 | 明显财经事件，存在至少一个明确重大因素 | CANDIDATE |
| S3 | 重大财经事件，影响或信息增量明显 | KEEP 竞争池 |
| S4 | 极重大事件，对公司、行业、市场、宏观或金融体系有显著影响 | 优先 KEEP 竞争 |
| S5 | S4 基础上形成当日核心关注事件 | HOT 竞争 |

> **S0—S5 的精确统计边界尚未标定**，因此它只用于描述事件量级与初筛（S0 可直接 DROP），**最终去留一律由 §17 同日竞争决定**，不得用等级直接顶替竞争。

## 14. 增强标签

增强标签用于**解释**事件为什么强，**不累加、不产生总分**。

EXTREME 极端涨跌／业绩／市场变化｜REVERSAL 盈亏反转、方向反转、事项反转｜FIRST 首次、首例、首份、第一｜HISTORICAL_BREAKTHROUGH 历史突破、创纪录、跨历史基准｜CONTROL_CHANGE 控制权／实控人变化｜LEADING_COMPANY 龙头、核心上市公司、重大金融机构｜MARKET_REACTION 显著股价／指数／资金／交易反应｜INVESTOR_IMPACT 对投资者有直接影响｜INDUSTRY_IMPACT 对行业供需、竞争格局或产业链有显著影响｜MACRO_IMPACT 对宏观经济或政策环境有显著影响｜FINANCIAL_SYSTEM_IMPACT 涉及金融体系或金融安全

以下三项**只作为证据，不作为强度**：OFFICIAL_RESPONSE（存在正式回应）｜MULTI_SOURCE（多个独立来源）｜OFFICIAL_DISCLOSURE（公司公告／监管披露）。

## 15. 专项规则

**业绩事件**
- 不得以利润绝对金额单独判断重要性；必须综合同比、环比、前期基数、市场预期、行业地位与市场反应。
- 重点识别极端增长、极端下降、盈亏反转、预期差、历史突破。
- 同一天大量业绩事件必须进入 EARNINGS_EVENT_GROUP 横向竞争，不能按绝对增长率简单排序。
- 同一公司的多条业绩信息合并为一个事件。
- 收入、营业收入、净利润属业绩指标，**不计入资本运作的大金额标签**。

**资本运作金额**
- 重大收购、出售、投资、融资、项目、股权交易属 CAPITAL_OPERATION 维度。
- **不得使用固定的 1／10／50／100 亿元阈值决定 KEEP**；金额只是事件影响的一项证据，必须结合主体重要性、交易性质、控制权影响、行业影响、市场反应和信息增量。

**一级市场私募融资**
默认不进入主稿竞争。**核心判据不是金额，而是是否存在可交易标的，以及它与二级市场／投资者的直接关联。**

| 情况 | 处理 |
|---|---|
| 无可交易标的、普通私募 A／B／C 轮 | DROP |
| 融资对应明确上市公司、上市公司控股／参股主体且对资本市场产生直接影响 | CANDIDATE，进入同日竞争 |
| 具有行业重大稀缺性、赛道标志性或历史突破，且对产业／资本市场形成明显信号 | CANDIDATE／KEEP 竞争 |
| 仅因融资金额较大，没有可交易标的和重大产业信号 | DROP |

> 证据：12 期原文中纯一级市场私募轮次事件 **0 条**；109 期正文库中真正成条的私募轮次只有 **1 条**（2022-03-24 售后宝完成 1 亿元 A1／A2 轮，且自带"国内售后服务 SaaS 赛道最大单轮融资"这一极端属性）。
> 反过来要收的两种：**动作方是上市公司**（定增、回购、对子公司增资、并购或参股未上市公司、辟谣入股传闻）；**未上市公司进公开市场**（递表、更新招股书、IPO 定价、挂牌——样本 6 条）。

## 16. 栏目骨架与条目候选池

**骨架定义在栏目级，不定义在条目级。**

12 期逐条切分实测：真正每期必在的只有栏目本身——宏观、产业动态、资本市场在 **12/12** 期均有内容；栏目内部的构成项**没有任何一项达到 12/12**（最高为 ETF／基金 8/12）。

| 栏目（栏目级骨架，必收） | 规则 |
|---|---|
| 宏观 | 每期必在；当日窗口内无有效宏观事件时可留空，但不撤销栏目 |
| 产业动态 | 每期必在（行业与碳中和合并统计）；规则同上 |
| 资本市场 | 每期必在（公司块与市场块合并统计）；规则同上 |

**条目级高频候选池**（出现即优先考虑，**不设必收**，全部照常参与同日竞争；括号内为 12 期出现期数）：

| 候选池条目 | 期数 | 候选池条目 | 期数 |
|---|---|---|---|
| 部委政策发布（宏观／产业） | 11/12 | 北向／南向资金 | 6/12 |
| ETF／基金（发行、分红、自购、清盘） | 8/12 | 官方核心经济数据（统计局、央行、海关、外汇局） | 6/12 |
| 行业协会与行业数据 | 8/12 | 监管与交易所动作 | 5/12 |
| 指数收盘综述 | 7/12 | 解禁 3/12；新股申购 2/12 | — |

**市场综述的收录基准**：采集发生在盘前，当期窗口内不存在"当日收盘"数据，收盘基准取**窗口内最近一个交易日**；A 股休市时以港股或外盘收盘替代（样本第 8 期 2022-10-08 用恒生指数 7 日收盘）。Agent 不得因为"当日没有收盘综述"或"没有北向资金"而阻塞该栏目。

**附录：样本实测清单（判条目时对照）**

*市场块*（12 期）：ETF／基金 8/12、指数收盘综述 7/12、北向／南向资金 6/12、监管与交易所动作 5/12、ETF 单列 4/12、券商研报观点 3/12、解禁 3/12、回购增减持 3/12、新股申购 2/12、债券与外资持债 2/12。
**一次都没出现过**：国债期货收盘播报 0/12、期货仓单变化 0/12、龙虎榜 0/12、涨跌幅榜 0/12。
> 判市场块新闻时问一句：**这条讲的是"钱在往哪走"，还是"价格今天动了多少"？** 前者收；后者只有当幅度大到破关键位（沪指跌破 3000 点）才收。

*公司块*（12 期约 65 个事件）：监管与司法 13 条（20%）、产品／价格／交付 11 条（17%，**全部带硬参数**）、辟谣与回应 10 条（15%，全部是上市公司回应自身传闻）、业绩与经营数据 7 条（11%）、股权与资本动作 7 条（11%）、IPO 与新股 6 条（9%）、人物 4 条（6%）、价格异动（带原因）3 条（5%）、商标／工商注册 3 条（5%）、诉讼与纠纷 2 条（3%）。
**一次都没出现过**：券商观点与评级 0/12、一级市场私募股权融资 0/12、政治消息 0/12。
> 两条入选线：**① 监管与司法是公司块第一大类型（20%），判公司事件优先看"有没有被查、被罚、被留置、被问询"；② 产品类收，前提是带硬参数（价格、日期、数量、资质、"首次"）——纯"发布会召开""新品亮相"不收。**

## 17. 同日竞争：固定比较顺序

所有 CANDIDATE 必须按以下顺序竞争。**只有前一项无法区分时，才进入下一项。禁止改成总分加权模型。**

| 顺序 | 比较维度 | 优先保留规则 |
|---|---|---|
| 1 | 事件影响范围 | 影响宏观／金融体系 > 全国性行业 > 重要行业 > 单公司 |
| 2 | 信息增量 | 新增事实越重大、越改变市场认知者优先 |
| 3 | 市场影响 | 已经产生或明确可能产生显著市场影响者优先 |
| 4 | 极端／稀缺程度 | 极端、首次、首例、历史突破、明显反转者优先 |
| 5 | 主体重要性 | 重大金融机构、龙头／核心上市公司、关键产业主体优先 |
| 6 | 投资者直接价值 | 直接影响投资者判断、风险或交易决策者优先 |
| 7 | 预期差 | 明显偏离此前市场预期者优先 |
| 8 | 代表性 | 能代表重要行业趋势、市场结构变化或典型风险者优先 |

> 该顺序是比较规则，**不是分数**；不得为每项设置权重后求总分。
> 同类事件达到多个候选时，先在事件组内竞争，再进入全局竞争。

## 18. 主稿规模与结构

- **口径**：宏观 + 产业动态（含碳中和）+ 资本市场（公司块 + 市场块）；**不含**民生、海外要闻、人物、财经日历，**也不含**重要公告（公告独立统计）。
- 实测（n=12）：**12—23 条，均值 17.2，中位 16.5**。
- 生产规则：**常态 12—20 条；重大数据日允许扩展至 23 条。**
  - "23"是重大数据日的容量上限，**不是普通日目标**。样本依据：23 条仅出现 1 期（第 5 期 2022-09-30），22 条 1 期（第 10 期 2022-10-25），属 n=12 下的**单一观测上界**，不是精确阈值。
- **栏目级骨架不额外扩容**：主稿 12—20（重大数据日 23）是**总量**，骨架内容计入其中。
- **总量优先于栏目区间。** §2 的三栏区间是分布参考（之和为 10—25），与总量 12—20（重大数据日 23）冲突时**以总量为准**：不得为了填满某一栏而突破总量上限，也不得为了凑总量而放任栏目失衡。极端组合（如宏观 7 + 产业 5 + 资本 13 = 25）不允许出现，须在栏内按同日竞争顺序淘汰末位。
- 容量不足时按同日竞争顺序淘汰末位候选；**不得为了达到下限而收录 S0 或明显低价值 S1**。

## 19. 公告池

**重要公告独立输出，不计入 MAIN_NEWS 的 12—20／23 条。**

| 等级 | 处理 |
|---|---|
| A 重大公告 | 必须进入公告池；若同时构成重大财经事件，可进入 MAIN_NEWS |
| B 重要公告 | 进入公告池；根据同日竞争决定是否进入 MAIN_NEWS |
| C 一般公告 | 按公告池容量上限（30 条）截断后展示，超出部分 DROP 并记录淘汰原因 |
| D 日常公告 | DROP |

A／B 级判定范围：控制权／实控人变化；重大收购、出售、终止重大收购；重大处罚、退市风险、重大司法风险；重大融资／定增；重大项目／合同；重大股权变化；重大业绩；重大资本运作。

- 先执行公告去重和事件合并；同一公告如果同时形成重大财经事件，只建立一个 event_group，可同时映射到 MAIN_NEWS 与 ANNOUNCEMENTS，但不得重复生成两个事件。
- 容量依据：12 期中 9 期设有公告板块，条数 **12—34，中位 26**；**30 条为按中位偏上取整的产品设计值，不是精确历史标定**。

## 20. HOT（热点提示 / 推送标题行）

**HOT 只从最终 KEEP 中产生。**

- **默认 4 条，允许 3—5 条。**
- 依据 804 期推送标题行统计（有效标题行 765 期）：3 条 49.9%、4 条 37.6%、5 条 2.2%、2 条 8.1%；**最新版式 2023-12 至 2025-02（n=279）中 4 条占 59.9%、3 条占 31.5%、5 条占 5.4%，3—5 条合计覆盖 96.8%**。
- 注：2022-09-26 至 2022-10-25 的 9 期曾使用文内"热点提示"块，该 9 期均为 4 条；但该块在新版式中已不再使用，样本仅覆盖一个月，**不作为生产依据**。

优先考虑：重大政策｜重大宏观数据｜极端市场事件｜极端业绩｜重大风险（监管、司法、金融、安全）｜重大资本运作｜龙头公司重大事件｜历史性突破｜官方回应型事件（高关注传闻与正式回应形成完整事件链）｜广泛投资者影响。

- **同一主题不得通过事件拆分占据多个 HOT 名额。**
- **常态型条目**（收盘综述、资金流向、解禁与新股、例行数据发布、公告汇总）**不进入 HOT**——样本 9 期共 36 条热点提示中，无一条为常态型条目。

## 21. 输出写法规范

选中之后怎么落笔，同样是标准的一部分。**写不出下面句式的条目，说明它没有通过前面的门，退回重判。**

### 21.1 每条必须能写出时间锚点

样本表达：`9月27日`、`12月13日5时至14日19时`、`截至9月23日`、`本周（12月18日-22日）`。
**写不出时间锚点，说明它不在窗口内，或者它根本不是新闻。**

### 21.2 正文条目句式：主体 + 动作 + 数字

- `国瑞科技公告，5月17日，公司收到中国证监会《行政处罚决定书》。`
- `4月份，全社会用电量7412亿千瓦时，同比增长7.0%。`

### 21.3 公告池句式：公司名 + 一句话 + 数字

- `盐湖股份：拟7.5亿元-15亿元回购股份，回购价格不超过40.62元/股。`
- `TCL中环：预计前三季度净利润49.3亿元-50.7亿元，同比增长78.53%-83.60%。`

### 21.4 标题行（HOT）句式

804 期 2523 条标题句实测：

| 指标 | 实测值 |
|---|---|
| 每句字数 | 平均 **17.2 字**，中位 16，P90 24，最短 5，最长 64 |
| 含数字 | 40.1% |
| 含金额或百分比 | 23.9% |
| 带感叹号 | 61.8% |
| 带问号 | 12.6% |
| 多条之间 | 用 `；` 连接 |

写法：一句一个事件，用 `；` 连接；句内给主体 + 动作，能带数字就带数字；语气可以短促，但**不得为了语气改变事实**。

### 21.5 栏目顺序

正文按 **宏观 → 产业动态 → 资本市场** 排列（2023-12 起版式；2022 年旧版式"公司→市场→宏观"已废弃）。公告池独立置于正文之后。

## 23. 禁止规则

1. 禁止因为标题重要而直接 KEEP。
2. 禁止因为政策来源权威而直接 KEEP。
3. 禁止因为监管处罚而直接 KEEP。
4. 禁止因为金额大而直接 KEEP。
5. 禁止因为同比超过固定百分比而直接 KEEP。
6. 禁止因为来源多而直接 KEEP；禁止同一事件多源重复入选。
7. 禁止传闻与官方回应拆成两条；禁止收入／利润金额当作资本运作金额。
8. 禁止使用固定金额阈值决定新闻等级；禁止使用固定总分阈值替代同日竞争。
9. 禁止为了凑足 12 条降低标准；禁止将重要公告全部塞入 MAIN_NEWS。
10. 禁止把人物本身作为财经新闻；禁止把历史海外栏目当作当前保留依据。
11. 禁止正文缺失时根据标题补事实。
12. 禁止将碳中和作为一级栏目；禁止把普通一级市场私募融资仅因金额大而纳入主稿。
13. 禁止同一公司同一事件重复占用名额。
14. 禁止将未经历史验证的参数描述为历史标定参数。
15. 禁止把采集端的**信源层级** `【官方／主流／其他】` 当作重要性或入选依据；它只说明这条要不要再找一个来源；禁止将它与公告池 A／B／C／D 分级混用。
16. 禁止直接采用采集端预分的栏目，必须按 §5 重新复检归栏。

# 第四部分 · 否决清单（命中即弃）

1. 过不了 §3 财经属性门的政治／政务消息（元首活动、会议程序、外交表态、部委工作表态）
2. 无信源的传闻——但"回应／辟谣"这个动作可以留（见 §3 例外表）
3. 零增量的刷屏新闻。**惯性数据归此类**：「连续第 N 周第一」「连续 N 个月增长」里，第 N 周与第 N-1 周之间没有增量，只有排名或量级变化的那个点才是新闻
4. 纯营销／无参数的新品发布／软文——**带硬参数（价格、日期、数量、资质、"首次"）的产品、价格、交付类要收**
5. 窗口外的旧闻——只能降为背景句，不单独立条
6. 纯观点与预测——必须有具体主体 + 数字才可入（样本 12 期里券商观点 0 条）
7. 无后果的流程性公告
8. 单一自媒体信源且无法核实
9. 归不进三个栏目的内容
10. 一级市场股权融资——判据是**它过不了 §3 财经属性门**（改变不了任何可交易资产的价格），不是因为它贴着"一级市场"这个标签。要砍的时候说清它答不出哪句话（例外见 §15）

# 第五部分 · 常见判错

**0. 政治消息的"重要性陷阱"（最容易犯的错）**
- 错：「中美经贸磋商在纽约举行」是大事，放开篇重点
- 对：这条消息没有一个字能落到价格、成本或规则上，弃

**1. 重大 ≠ 上**
- 刊发了但不进标题行：二十大代表全部选出（重大，但不具体）
- 进了标题行：诺安基金原总经理奥成文涉嫌严重违纪违法被查（有名字、有冲突；主体是**金融机构高管涉案**，不是政治活动）

**2. "重要但没数字" vs "普通但有数字"**
- 出局：某专家表示市场将震荡筑底（12 期里 0 条）
- 入选：13 名投资者起诉鲜言操纵证券市场获赔 470 万余元

**3. 传闻不选，"回应"选**
- 出局：中国移动可能入股腾讯（无信源传闻）
- 入选：腾讯回应称该消息不实（主语是回应方，是事实）

**4. 重复回应不等于零增量**
- 入选：海天味业第三次回应食品添加剂"双标"风波——"第三次"本身就是新进展

**5. 够具体但不够大 → 进公告池，不进栏目**

**6. 政策类看"改了没有"，不看"说了没有"；公司类看"后果"，不看"表态"**
- 入选：证监会把回购触发条件从"20 日内跌幅累计 30%"放宽到"20%"（改了门槛）
- 入选：吉林高速连续两年不分红、两年赚 9.4 亿，上交所发问询函（数字 + 监管动作）
- 出局：某公司称"高度重视并持续优化"（无后果）

# 第六部分 · 运营与治理

## 24. 更正与撤稿

- 已发布条目出现事实错误（数字、主体、时间）时：**在下一期同栏目位置发布更正**，不删旧文、不做无痕修改。
- 更正只更正事实，不重新论证入选理由。
- **触发复盘的三种情况**：
  1. 同一事件连续两期被收录 → 窗口裁剪（§8.1）失效；
  2. 收录了无标的事件（未上市公司、不可交易主体）→ 财经属性门（§3）失效；
  3. 被证伪的传闻被当成事实收录 → 未做交叉验证（§7.3）。
- 每季度统计一次"更正条数／总发布条数"，作为标准有效性的观察指标。

## 25. 版本管理与变更

- 版本号标注在主标题（当前 V1.0）。每次修改必须在本节登记：日期、改动条目、依据、批准。
- **新增或修改任何数值参数**（阈值、条数、区间），必须同时给出样本依据与样本量（n=）；拿不出依据的写"待标定"。
- 参数变更须有回测支持：先在历史期上跑一遍，确认 precision／recall 不下降，再进生产。
- 禁止在无记录的情况下直接改规则文本。

| 版本 | 日期 | 改动 | 依据 |
|---|---|---|---|
| V1.0 | 2026-09-22 | 合并《新闻筛选方法论 v1—v9》与《Agent 规范 V2.0—V2.1.2》，形成唯一标准 | 12 期原文 + 804 期清单 + 109 期正文库 |
| 待填 | — | 补齐待标定参数：总分阈值、金额阈值、单公司上限、单行业上限、S0—S5 边界 | 109 期逐期回测 |

## 26. 合规提示

- 栏目定位是财经信息整理，**不构成投资建议**；涉及具体标的只陈述事实与已公开数据，不做买卖推荐、不给目标价。
- 涉及在审案件、被立案调查主体，一律沿用来源中的法定表述（"涉嫌""被立案调查""公告称"），不得自行定性。
- 引用他人研报、预测数据必须标明来源与时间。
- 不收录未公开信息；不收录无信源的传闻（见 §3 例外表与否决清单第 2 条）。

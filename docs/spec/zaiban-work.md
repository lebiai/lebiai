## 0. 一句话

**在办** = 停下来还欠的交差，每一笔必须有「哪天前」。  
**回顾** = 一段日子里，哪些已经可以认领为做成了——给人下周一接着干、对外能说「干了什么」。  

两面一件事：做成了 ↔ 还欠。  
不是聊天摘要，不是文件变更清单，不是离开时抽规则的那套蒸馏。

强化：① 跨次看见还欠的 ④ 过了敢问还做不做 ⑤ 一段日子能复盘。

## 2. 三层不要混

| 层 | 是什么 | 寿命 | 落点 |
|----|--------|------|------|
| 当次拆步 | 这一轮怎么干完 | 本会话 | `todo_write` |
| **在办** | 停下来还欠的交差（必有期限） | 跨会话，勾完或丢掉才消失 | `commitments.json` |
| **回顾** | 这段日子做成了什么（周报底稿） | 按区间一份，再蒸覆盖 | `reviews/*.md` + `index.json` |
| 手感规则 | 以后都该这么干 | 长期，一类事一条 | 记忆宫殿（离开蒸馏） |

离开蒸馏抽规则，进「它记得的」。回顾抽工作，进回顾页。禁止混写。

## 3. 一条在办

用户认的是**一句标题 + 一个期限**。

| 字段 | 用户语言 | 规则 |
|------|----------|------|
| 标题 | 做什么 | 他的动词+宾语。禁止空话标题。 |
| 期限 | 哪天前 | **必填。** 人话保留，且必须解析到本地日期。见 §4。 |
| 状态 | 开着 / 待收下 / 等别人 / 做完 / 不做了 | 见 §6 |
| 完成算什么 | 交差标准 | 可空。不挡「开始做」。 |
| 来源 | 哪次对话 / 手建 | 可点回。 |
| 备注 | 等谁 | 一行。 |
| 别名 | 后来又那么叫 | 合并时追加。 |

开着宜少。超过 7 条：搭子先砍；界面说「先清再加」。

## 4. 期限

### 4.1 落到哪一天

| 人说 | 落成 |
|------|------|
| 今天 / 今晚 | 当天 |
| 周五前 / 周五 | 本周五；已过则下周五 |
| 这周 | **本周五**（不是周日） |
| 下周 | 下周五 |
| 8/20 | 那天 |
| 以后、有空、尽快 | **不收。** 问「哪天前？」 |

禁止系统通知、日历订阅、循环。期限只用来：排序、显示、判断过了、回顾「本周该交的」。

### 4.2 记下时

- 对话里带了日子 → 一并收下。  
- 对话里没日子 → **不建**，问一句「哪天前？」芯片：今天 / 这周 / 下周，或他说一天。  
- 自己记 → 标题 + 同一排芯片 + 选一天。不选不能记下。  
- 待收下点收下 → 同样要日子，无期不能生效。  
- 旧数据没有日期 → 视为过了，逼补日子或丢掉。

### 4.3 过了

过了 = 日期已过去，条仍开着。

- 不自动丢掉，不自动改期。  
- 仍算开着的债，排最前，形态变成「过了 · 原定…」。  
- 对话一事一点：「过了，还做吗？」  
  - **还做** → 必须换新期限。  
  - **做完了** → 勾完。  
  - **不做了** → 丢掉。  
- 当天问过不再催。关着 App 不闹。  
- 「等别人」过了问「还在等吗」。

## 5. 用户怎么走 · 在办

### 5.1 对话里收下（主）

人说记下 / 这周三件 / 谋划收束。先对开着的列表。同一笔则问是不是。不是则按完成标准新建。没期限就先问期限。成功立刻出现在抽屉。

人正在这轮做完的，不收成在办。

### 5.2 自己建

抽屉在办页「记」。标题 + 期限芯片。撞车问合并。授权锁定仍可手建、改、勾、丢掉。

### 5.3 改与删（必须能看见）

每条**常驻**四个动作，不靠鼠标悬停：

| 动作 | 用户语言 | 结果 |
|------|----------|------|
| 改 | 改标题 / 改期限 | 记下新句或新日子。改标题**不得**清掉期限。 |
| 做完 | 做完 | 离开开着的列表。 |
| 丢掉 | 丢掉 | 不做了。要确认一句（短）。 |
| 开始做 | 点标题，或对话里那条「开始做」 | 回对话，输入框预填「开始做：…」。人自己按发送。不自动开跑。不问「完成算什么」。 |

「等别人 / 拆开 / 回那次对话」在点「改」之后给。先写等谁再点「等别人」；先写至少两行再点「拆开」。不要第三套进度条。

### 5.4 离开余债

仍只建议 0–1 条进待收下。收下时补期限。7 天未点头丢掉。

### 5.5 对话递回（一事一点）

| 时刻 | 说什么 |
|------|--------|
| 新开对话且有开着的 | 还有 N 件，最紧的是… |
| 问今天 / 这周 / 在办 | 按期限排，敢砍 |
| 期限过了 | 过了，还做吗？（还做必须换期） |
| 待收下 | 上次那条收吗？收下要日子 |
| 近义两条 | 像一件，并吗？ |
| 开着已多还往上堆 | 再加会撞 |

无系统通知。无开着的 → 当没有。

## 6. 状态

| 状态 | 看见 | 算开着？ | 递回 |
|------|------|----------|------|
| 开着 | 标题 + 期限 | 是 | 是 |
| 过了 | 同一条 + 「过了 · 原定…」 | 是（仍开着） | 问还做吗 |
| 等别人 | + 「等…」+ 期限 | 是 | 是 |
| 待收下 | 更浅，收下 / 丢掉 | 否 | 只问收不收 |
| 做完 / 不做了 | 默认不展示；在办页可折「最近完成」 | 否 | 否 |

过了不是新状态机值，是开着 + 日期已过。

## 7. 在办长什么样

- 每条都能扫到期限，和标题同级可扫。  
- 今天到期：写「今天」，加重，不红。  
- 过了：琥珀「过了 · 原定周五」。  
- 排序：过了 → 今天 → 越近越前。  
- 右上角数字 = 开着的条数；有过了的，数字用过了的色。  
- 空态：教一句「记下周五交方案」，并露出期限芯片。  
- 视觉跟现有 GUI：主色蓝，禁止黑主按钮、禁止悬停才给改删。

## 8. 回顾

### 8.1 为了什么

把这周从「忙过」变成「做成过」。  
用处只有三处：下周一接着干；对外能说干了什么；这周没有能交的就认空。  
蒸不出这三句，就不要蒸。

### 8.2 蒸什么

周报底稿，三栏：

| 栏 | 用户语言 | 算 | 不算 |
|----|----------|----|------|
| 干了什么 | 做成了什么 | 他的动词+宾语 | 查了、跑了、写了个脚本 |
| 交差文件 | 能交给别人的内容 | doc/docx/pdf/md/xlsx/pptx/rtf 等 | py/rs/js、临时文件、隐藏文件、/tmp、测试字 |
| 还欠 | 还开着的在办 | 列表里有的 | 模型发明的债 |

证据先砍再蒸：候选路径只留内容件。模型没看见脚本，就不会写成产出。法规下载默认是材料，不是成果——除非这件事就是汇编。

### 8.3 怎么走

- 目录页：过往列表 + 「回顾这段」+ 区间芯片 + 节奏。  
- 蒸完进入**读账**（独占）。左上角 **收起** 回目录。Esc 关整个抽屉。  
- 读账：日期作题，总述一段，三节留白。文件是附件，不是正文。  
- 再看一次在读账底栏。同一区间覆盖上一份。  
- 节奏：周五 / 周六 / 周一 / 不要问。进门问一句「要回顾这段日子吗？」不是模态。

### 8.4 空 / 载 / 错

| 态 | 看见 |
|----|------|
| 这段没对话 | 「这段日子没有对话」+ 换区间 |
| 蒸完没有能交的 | 干了什么可空；不要用脚本凑 |
| 载 | 「正在回顾…」，可关抽屉 |
| 错 | 「没蒸成，过会儿再试」 |

## 9. 明确不做什么

- Todoist / 系统提醒 / 日历 / 循环待办  
- 默认周日催回顾；关着 App 开火  
- 过期自动丢掉或自动改期  
- 把离开蒸馏和回顾写成一个东西  
- 用 py / 测试文件冒充产出  
- 在办进「它记得的」或顶栏第四项  
- Server / Flutter / IM 写路径（未接线标计划中）

## 10. 和此刻实现的差距（诚实）

| 条款 | 此刻（2026-08-17 收口后） |
|------|------|
| 期限必填 | 开着的债无日期不能落盘；尽快拒绝；手建 / 待收下 / 对话新建要芯片 |
| 过了换期 | Cue 问还做 → 必须选新期；当天问过不再催 |
| 改 / 删 | 每条常驻做完 / 改 / 丢掉；改标题不清期限 |
| 回顾周报口径 | 证据先砍脚本和临时文件 |
| 读账 / 收起 | 目录与读账拆开；这段已蒸过先写出来，再点进去读 |
| 空态 | 教一句并露出期限芯片 |
| 其它入口 | 仍仅桌面 GUI。Server / Flutter / IM 未接线 |

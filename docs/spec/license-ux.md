## 2. 主状态机

用户任意时刻仅一主状态：

| 状态 | 条件（产品语言） | 对话等主能力 | 全屏锁 | 侧栏电池 |
|------|------------------|--------------|--------|----------|
| **A 试用中** | 无有效授权码，且试用未结束 | ✅ | 否 | 试用剩余 |
| **B 已授权·充裕** | 有效授权，剩余 **> 3 天** | ✅ | 否 | 正常 |
| **C 临期** | 有效授权且剩余 **≤ 3 天**且未过期；**或**试用剩余 **≤ 3 天**且未结束 | ✅ | 否 | 警告 |
| **D 锁定** | 试用结束且无有效码；或授权已过期；或码无效且无可用试用 | ❌ | **是** | 过期/空 |
| **E 时间异常**（实现可选） | 系统时间明显回拨等 | 产品默认：提示校对时间；严重时可按 D | 按实现 | 异常 |

```
首次启动 → 写入 trial_started_at → A
A ──贴有效码──→ B 或 C
A ──试用到期无有效码──→ D
B ──剩余≤3天──→ C
C ──到期/试用结束──→ D
C/D ──贴有效新码──→ B 或 C
```

**续期不另设状态**：验证成功并覆盖本地授权后，按新到期日重算 B/C。

## 3. 校验与续期（同一逻辑）

### 3.1 何为「有效授权」

- 客户端用**内置公钥**验签通过；
- 载荷含本产品标识与 **`exp`（到期时刻）**；
- 当前本地时间 **&lt; exp**（允许小额时钟偏差，实现定）；
- **不**做机器码绑定。

技术形态（实现指引，非 UI）：签名载荷（如 JWT/类 JWT），**禁止**仅靠对称加密藏期限。

### 3.2 试用

- 无有效授权时：`now < trial_started_at + 3 天` → 状态 A 或试用临期 C。
- 试用期内贴有效码 → **立即**以授权为准，侧栏/设置不再以试用为主文案。
- 清除本机数据可能导致试用重置（不绑机的已知取舍；设置中可一句说明）。

### 3.3 粘贴/更新授权码（激活 = 续期）

用户路径永远是：

1. 获得授权码（站外：微信 iodine001）；
2. 粘贴到输入框；
3. 确认；
4. 同一验证；
5. 成功则**覆盖**本地授权并刷新 UI。

| 情况 | 产品行为 |
|------|----------|
| 验签失败 / 非本产品 | 人话错误，保留输入内容 |
| 码已过期 | 提示过期，引导加微信 |
| 新码 `exp` **晚于**当前有效授权 | 接受并覆盖 |
| 新码 `exp` **早于**当前有效授权 | **拒绝覆盖**，提示未更换（防误贴旧码） |
| 与当前码相同 | 提示已是当前授权，不恐吓 |
| 成功 | 无需重启；展示「可用至 YYYY-MM-DD」 |

客户端**不**解析「月/季/年」套餐给用户选；套餐只体现在签发方写入的 `exp`。

### 3.4 过期后能力

- 主能力（对话等）：**关闭**。
- **必须**能完成：见全屏、复制微信号、粘贴授权码、激活成功后回到 App。
- API Key 等配置**保留**；文案可说明「授权恢复后即可继续使用」。

## 4. 用户触点

### 4.1 侧栏电池

- **数据**：与设置授权区块**同一状态源**。
- **展示**：试用 / 充裕 / 临期 / 过期（颜色分层）；tooltip 或旁注剩余与到期日。
- **点击**：打开设置「授权」并尽量 **focus 输入框**（锁定态下若全屏已在，则聚焦全屏输入）。

### 4.2 设置 → 授权

自上而下：

1. 状态文案（试用中 / 已授权 / 已过期）  
2. 绝对到期日（或试用结束日）+ 相对剩余  
3. 电量条（时间比例）  
4. 授权码输入 + 主按钮（激活 / 更新授权，同一逻辑）  
5. 购买：微信 **iodine001** + **一键复制**  
6. 简短说明：码仅存本机；续期仍粘贴新码  

### 4.3 临期日更弹窗（可关闭）

**适用范围（已确认）：**

- 正式授权剩余 ≤ 3 天；**以及**
- **试用最后 3 天**。

**频率：**

- 每个**本地日历日**最多 **1** 次；
- 记录 `last_renew_nudge_date`；点「稍后」当日不再弹；
- 成功续期/激活离开临期后不再弹；
- 进入 **D 锁定** 后**不再**用本弹窗（改全屏锁）。

**时机：**

- 冷启动进入主界面稳定后；或跨日后首次回到前台；
- **避开**对话 streaming 中（本轮结束后或下次进入再弹）。

**内容：**

- 标题：授权即将到期 / 试用即将结束（按是否已有正式授权区分文案）；
- 剩余天数或「今天到期」+ 日期；
- 主按钮：去粘贴授权码（直达输入区或设置授权）；
- 次按钮：稍后提醒；
- 辅助：加微信 iodine001（可复制）。

### 4.4 过期全屏锁（不可关闭）

- 层级：与欢迎/Onboarding 全屏同级或更高，盖住主壳。
- **不可**：点遮罩关闭、跳过、Esc 关闭、仅警告仍可进对话。
- **必须展示（已确认）：**
  - 品牌（乐彼AI / lebi-AI）
  - **Slogan**（如：越用越像你的手感）
  - 说明：授权已到期，续期后可继续
  - 授权码输入 + 提交
  - 购买：微信 iodine001 + 复制
- 成功：卸下全屏 → **回到进入锁之前的界面**（或对话默认）→ 成功提示含新到期日。

## 5. 主电影脚本（丝滑路径）

```text
【新用户】
安装 → 欢迎/配置 API Key（不强制授权）→ 试用 3 天 → 侧栏见试用电池

【购买/续期】
点电池或设置→授权 → 复制微信 iodine001
→ 站外付款获码 → 回 App 粘贴 → 即时生效，无需重启

【临期（含试用最后 3 天）】
每天最多 1 次温和弹窗 → 去粘贴 或 稍后 → 仍可继续使用

【到期】
打开即品牌全屏锁 → 复制微信 / 粘贴码 → 解锁回原处
```

用户只需记住：

1. 侧栏电池 = 使用期状态  
2. 续费找微信 **iodine001**  
3. 收到码就**粘贴**（与第一次相同）

| 备份 | 安装说明可提：备份数据目录含授权；亦请自行保存授权码邮件/聊天记录 |

## 7. 统一文案主词

| 用 | 避免 |
|----|------|
| 授权码 | 与 API Key 混称 |
| 激活 / 更新授权 | 多套「续期向导」 incantation |
| 试用剩余 | 长篇套餐对比（客户端不做商城） |

成功示例：

- 首次：`授权已生效，可用至 YYYY-MM-DD`
- 续期：`已更新授权，可用至 YYYY-MM-DD`

## 8. 验收清单（用户语言）

- [ ] 新装 3 天内可不贴码使用主能力（在已配 Key 等前提下）  
- [ ] 试用最后 3 天与正式临期一样，每天最多 1 次提醒弹窗  
- [ ] 侧栏 + 设置均能看到剩余/到期并进入粘贴  
- [ ] 粘贴有效码无需重启即生效  
- [ ] 误贴更早到期的码不会覆盖当前更好授权  
- [ ] 过期后全屏不可关，含品牌与 slogan、输入框、iodine001  
- [ ] 过期全屏贴码成功立即恢复使用  
- [ ] 不绑机：换机可贴同一有效码（产品接受共享风险）  
- [ ] 无强制联网才能激活

本文不得另立品类或把「在办」写成用户默认主路径。默认主路径仍是**对话**。

---

## 0. 一句话

在办 = **停下来之后还欠的交差**。  
对话里谋划、记下、自己建，都可以收下；下次在对话里递回来。  
不是话题摘要，不是当次步骤，不是记忆规则，不是系统闹钟。

强化爱上：① 跨次被准确理解 ② 建议像为他定制 ④ 敢顶你（先砍再加）⑤ 做完可进复盘。

## 1. 已拍板决策

| # | 议题 | 结论 |
|---|------|------|
| 1 | 对象 | 跨次还欠的交差。当次拆步仍用 `todo_write`。规则仍用记忆。 |
| 2 | 入口 | **对话里收** + **人自己建**。同一类对象、同一份列表。 |
| 3 | 切法 | 问完成长什么样。默认**偏少、偏完整**；步骤不下沉。人已报「三件事」听人的。拿不准给出一种切法，你定。 |
| 4 | 离开 | 只扫**余债**。安静建议 0 或 1 条（偶尔 2）。进同一列「待收下」，**不算正式债**。不弹窗，不进进化收件箱，不挡走。 |
| 5 | 近义 | 并的是**同一笔开着的债**。标题跟人认得的那句。已完成不当合并对象。拿不准就问。默认少建、先折进旧的。 |
| 6 | 提醒 | **只在对话里递回**。不做系统通知 / 日历 / 循环任务。 |
| 7 | 摆放 | 主操作在对话。次操作在**对话顶栏右侧按钮 → 右侧抽屉**（见 [`zaiban-drawer-review.md`](./zaiban-drawer-review.md)）。**不**进侧栏、**不**进「它记得的」、**不**新增顶栏。 |
| 8 | 授权 | 看列表 / 手建 / 勾完：**不**走对话门禁。从对话里抽、让搭子排：走 `can_use_main`。 |
| 9 | 其它入口 | v1 只做桌面 GUI + 共享引擎。Server / Flutter **计划中**。IM **不写**（fail-closed）。 |

## 2. 三层不要混

| 层 | 是什么 | 寿命 | 现有落点 |
|----|--------|------|----------|
| 当次拆步 | 这一轮怎么干完 | 本会话 | `todo_write` / `TODOS.md` |
| **在办** | 停下来还欠的交差 | 跨会话，勾完或丢掉才消失 | **本文（待建）** |
| 手感规则 | 以后都该这么干 | 长期，一类事一条 | 记忆宫殿 |

**现在做 vs 以后欠：** 这轮正在写、已经交了 → 不立项。写到一半离开 → 一条「写完…」，锚在那次会话。

---

## 3. 一条在办长什么样

用户认的是**一句标题**。字段为后台与侧栏次要信息，创建时不逼填表。

| 字段 | 用户语言 | 规则 |
|------|----------|------|
| 标题 | 做什么 | 他的动词+宾语。抽取器不得改写成空话（禁止「优化内容交付」）。 |
| 状态 | 开着 / 待收下 / 等别人 / 做完 / 不做了 | 见 §5 |
| 完成算什么 | 交差标准 | 可空。开始做时再问一句。 |
| 软期限 | 「周五前」 | 原话保留；能解析出日期则另存，供「过了」递回。不是日历强制。 |
| 来源 | 哪次对话 / 手建 | 会话 id 可点回；手建则无。 |
| 备注 | 等谁、一句为什么 | 一行。等别人用备注，不另开工作流。 |
| 别名 | 后来又那么叫 | 合并时追加，不改他认的标题。 |

**开着的宜少。** 超过 7 条：搭子先砍再收；侧栏提示「先清再加」。不禁止人手建（主权），但要难看一点、敢说话。

## 4. 用户怎么走

### 4.1 对话里收下（主）

1. 人说「帮我记下：周五前把改稿发给老王」，或「这周就三件事：A、B、C」，或谋划收束「那就这些」。  
2. 搭子先对开着的列表（§6）。同一笔 → 「是不是这条？」或折进旧的。  
3. 不是同一笔 → 按完成标准新建。已切好的数字听人的。拿不准只给**一种**切法，问一句。  
4. 人点头或工具写成功 → 侧栏那条立刻出现。  
5. 失败 → 一句人话 + 仍可自己建。不弹原始错误。

人正在这轮做完的事，不收成在办。

### 4.2 自己建（次，但必须有）

1. 侧栏在办块点「记一条」或空态那句。  
2. **一个输入框**，回车即建。不填期限、不选项目。  
3. 和开着的标题明显撞车 → 「已有：周五交改稿。合并？」合并 / 仍新建。不默默吃字。  
4. 授权锁定时仍可手建、勾完。

### 4.3 离开会话（余债，不是第二次立项）

与进化离开**并行、互不抢戏**：

- 进化：照旧安静蒸馏 → 待审进「它记得的」。默认不弹窗（`pop_inbox_on_leave` 仍默认关）。  
- 在办：另跑余债扫描。**0 或 1 条建议**（偶尔 2）。写入「待收下」。  
- **不**挡切换会话。**不**做第二个离开大弹窗。**不**把余债推进化收件箱。

跳过扫描：回合不足（与 `reflect.min_turns` 同纪律）、问候场、当轮已交、开着的已覆盖、人没说过任何「以后还要交差」的话。

待收下 7 天未点头 → 丢掉，不打扰。

### 4.4 对话里递回（提醒）

只在这些时刻开口，一事一点：

| 时刻 | 说什么 | 不说 |
|------|--------|------|
| 新开对话且有开着的 | 「还有 N 件在办，最紧的是…」 | 每轮进门念整表 |
| 人问今天 / 这周 / 在办 | 用开着的排，敢砍 | 假装记得没有的条 |
| 聊到相关 | 「这跟那条改稿是一件事吗」 | 没锚却提 |
| 又往上堆、开着已多 | 「再加这两件，周五那条会撞」 | 默默答应 |
| 软期限过了仍开着 | 「周五那条过了，还做吗」 | 催命、红点轰炸 |
| 有待收下 | 「上次那篇还没收下，收吗？」 | 把它当成已生效的债 |
| 近义两条都开着 | 「这两条像一件，并吗？」 | 后台偷并 |

无开着的 → 当没有。去谋划或去干活。

### 4.5 开始做 / 勾完

- 点一条标题 → 回到**对话**，输入框预填「开始做：{标题}」，人按发送。不自动开跑。  
- 当次步骤仍用 `todo_write`。禁止第二套进度条。  
- 「做完了」可在对话说，也可在侧栏勾。做完离开开着的列表。  
- 只有「下次同类还能用的做法」才走现有进化。实例本身不当规则。

### 4.6 切错了

侧栏或对话均可：**并、拆、改标题、丢掉**。  
宁可先收成一件再拆，不要先碎成八件。拆开时每条仍要是独立交差。

## 5. 状态

| 状态 | 用户看见 | 算开着的债？ | 递回？ |
|------|----------|--------------|--------|
| 开着 | 正常一条 | 是 | 是 |
| 等别人 | 同一条 + 一行「等…」 | 是 | 是（「还在等老王」） |
| 待收下 | 更浅、有「收下 / 丢掉」 | **否** | 只问收不收 |
| 做完 / 不做了 | 默认不展示 | 否 | 否 |

不做看板列、不做人天、不做子任务树。

---

## 6. 近义合并

并的是**同一笔开着的债**，不是「句子像」。

- 「周五交改稿」≈「把公众号那篇弄完」→ 并。标题留人认得的。  
- 「交改稿」≠「约设计」。  
- 「改标题」撞上「交改稿」→ 步骤，吸进备注或不建。  
- 「等老王」撞上同一改稿 → 一条 + 备注。  
- **已勾完的**不当合并对象。再改一版是新的一笔。

| 时机 | 做法 |
|------|------|
| 对话收 / 离开建议 | 先看开着的 + 待收下。像 → 不新建。 |
| 手建撞车 | 问合并。 |
| 已经并排两条 | 下次排期或问今天时问一句。不偷并。 |
| 人说并 / 拆 | 听人的。 |

自动折只允许完成标准明显是一个。拿不准就问。

## 7. 看起来怎么样

与现有 GUI 同色、同圆角、克制动效。像对话的延伸，不像后台表。

### 7.1 摆放（以抽屉规格为准）

会话侧栏**不再**放在办。按钮在对话顶栏右侧，内容在右侧抽屉。细则与回顾页见 [`zaiban-drawer-review.md`](./zaiban-drawer-review.md)。

在办页里的列表规则仍是：空态教一句记下；待收下在上；开着的列出标题（等别人次要色）；超过 7 条先清再加；点标题 = 开始做。

### 7.2 对话里

- 工具事件一句话：「已记下：周五交改稿。」可点到抽屉里那条。  
- 递回是回复里的一小段，不是横幅、不是角标风暴。  
- 确认切法 / 合并：跟在回复后，主按钮一个（收下 / 就是这条 / 拆开）。

### 7.3 不出现的面

- 「它记得的」第三 Tab  
- 顶栏第四项  
- 离开全屏审在办  
- 日历、看板、系统通知  
- 进化待审里混「还欠周五交稿」

### 7.4 错态

| 情况 | 看见 |
|------|------|
| 写下失败 | 「没记下，再试一次或自己在抽屉里记。」 |
| 列表读失败 | 抽屉里一句短错，不影响对话。 |
| 近义未决 | 问句，不丢任何一条。 |

加载：侧栏骨架一行即可，不转圈挡对话。

## 8. 系统提示与工具（实现须服从）

- 身份协议仍只在 `hermes-core::companion`。可增一小节 **Open work（在办）**：欠债才收；步骤用 `todo_write`；少建；先对开着的列表；敢砍；无条不装记得。  
- ** Progressive Disclosure：** 每轮最多注入开着的标题（建议 ≤7）。正文、来源按需再读。禁止整库灌进系统提示。  
- 注入时机：人问今天/这周/在办/记下；本轮文本打中某条；当天第一次开口且有开着的（一句）。  
- 引擎工具（①，不是 skill）：列出 / 收下或更新 / 勾完或丢掉。桌面默认放行（与 `memory_save` 同级可见事件）。`requires_confirmation`：删/丢掉可按删除记忆同级。  
- 离开余债是**独立扫描**，禁止塞进 `ReflectionOutput` 的 memory/skill 数组。  
- IM 白名单不含写工具。无确认表面 fail-closed。  
- `todo_write` 行为与文案不改。

---

## 9. 数据（实现须服从）

- 本机一份明文，根在 `data_root()`（`~/.lebi-ai/` 或用户迁移后的目录）。建议 `commitments.json`（原子写）或同等可备份格式。  
- **不**写入 `memories/`、`skills/`、`pending-review.json`、会话 JSONL 当真相。会话里只留锚（id）。  
- 用户可打开文件备份；无数据库。  
- 已完成 / 丢掉保留一段时间供审计即可，不进默认列表、不进系统提示。

## 10. 明确不做什么（v1）

- Todoist / 系统提醒 / 日历同步 / 循环规则 / 多人看板  
- 每轮微反思抽任务  
- 离开时把整段对话拆成多条生效在办  
- 用记忆冒充在办，或用在办冒充规则  
- 生活催办当主叙事  
- Server / Flutter / IM 写路径（未接线须标计划中，不得写成已交付）

「每周一排本周」是手感，进记忆，不进循环在办。

## 11. 验收清单（用户语言）

- [ ] 说「记下周五交改稿」→ 侧栏出现同一句话，不是空话标题  
- [ ] 说「这周三件事 A B C」→ 三条，不是一条也不是九条步骤  
- [ ] 东拉西扯一个项目后离开 → 最多 1 条待收下，或不出现；无离开大弹窗  
- [ ] 再开对话 → 至多一句递回；不是每轮问候念表  
- [ ] 「把公众号那篇弄完」在已有「交改稿」时 → 问是不是那条 / 折进，不并排三条  
- [ ] 手建「方案」撞上已有 → 问合并；标题不被改掉  
- [ ] 点一条 → 回到对话，预填「开始做：…」，发送后当次步骤仍是过程，不是新在办  
- [ ] 勾完 → 列表消失；不自动变成一条记忆  
- [ ] 授权锁定 → 仍能看、建、勾；不能靠对话抽/排  
- [ ] 「它记得的」里没有在办 Tab；进化待审里没有「还欠周五」  
- [ ] 开着超过 7 条时搭子敢砍；界面不舒服地怂恿再加

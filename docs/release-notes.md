# 乐彼AI 1.0 发布说明

> 越用越像你的手感。接得住你的想法，推得动你的事。

## 1.0 带来的

- **开箱即用**：默认 DeepSeek，只填一个 API Key 就能开工，获取 Key 有内置图文教程，不用装任何额外东西。
- **欢迎仪式更短**：起个名字、勾选你常做的事，30 秒进入正事；没准备好也能跳过，随时回来。
- **称呼处处一致**：欢迎页填的名字，会同步到侧栏、问候和对话里；设置里改名即时生效。
- **技能开箱非空**：内置记忆宫殿 / 技能创作 / 找技能，还能新建属于你自己的技能。
- **设置更顺手**：问候条 + 分区卡片，改动即存；切换语言、主题、模型服务立即生效，不用重启。
- **数据位置可改**：点「更改位置」用系统目录选择器选新位置，自动迁移，不再手输路径。
- **零打扰**：没配 Key 也不弹报错横幅，真正要发消息时才提醒你去设置。
- **对话守护**：未配置 API Key 时禁止发起对话，输入内容不会丢。

## 安装

- **macOS**：下载 `.dmg`，双击打开后把 `lebi-AI` 拖入「应用程序」。首次打开若提示“来自身份不明的开发者”，右键（或按住 Control 点击）图标 →「打开」→ 确认即可。
- **Windows**：下载 `-setup.exe`，双击按向导安装。若出现 SmartScreen 提示，点「更多信息」→「仍要运行」。

## 隐私与数据

- 所有对话、记忆、技能、设置都保存在**你自己的电脑**上（macOS `~/.lebi-ai`，Windows `%USERPROFILE%\.lebi-ai`）。
- 只有你主动使用 AI 模型服务（发送消息）时才调用对应服务商的 API。
- 卸载/重装不影响已有数据；升级安装包直接覆盖，数据原样保留。

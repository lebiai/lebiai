# 安装与首次使用（拿到安装包后）

> **种类：** B 用户说明书（非权威）。冲突以 P0 v0.11 为准。
> 面向拿到**桌面**安装包的用户（当前默认交付）。数据默认只在**本机明文文件**。
> 桌面有 3 天试用；到期后需授权码。授权本机校验，不是云账号。

## 1. 安装包是什么

| 平台 | 文件 | 说明 |
|------|------|------|
| macOS | `lebi-AI_<版本>_<架构>.dmg` | 磁盘镜像，拖入「应用程序」即完成安装 |
| Windows | `lebi-AI_<版本>_<架构>-setup.exe` | NSIS 安装向导，默认装到当前用户 |

> **关于「未签名」提示**：当前安装包未做代码签名/公证，所以 macOS 的 Gatekeeper 与
> Windows 的 SmartScreen 首次会拦截一次。这不是病毒，按下面的步骤放行即可；
> 正式对外分发前会补签名（开发计划中）。

## 2. macOS 安装

1. 双击打开 `lebi-AI_...dmg`。
2. 把 **lebi-AI** 图标拖进「应用程序」文件夹。
3. 打开「应用程序」里的 lebi-AI。首次会提示 **「lebi-AI 无法验证开发者 / 来自身份不明的开发者」**：
   - 方式一（推荐）：右键点 lebi-AI → **打开** → 再点「打开」。
   - 方式二：系统设置 → **隐私与安全性** → 滑到「安全性」→ 点 **「仍要打开」**。
4. 之后正常双击即可打开（只需放行一次）。

## 3. Windows 安装

1. 双击运行 `lebi-AI_...-setup.exe`。
2. 若出现蓝色 **「Windows 已保护你的电脑」**（SmartScreen）：
   - 点 **「更多信息」** → **「仍要运行」**。
3. 按向导完成安装（默认「仅当前用户」，不需要管理员权限）。
4. 从**开始菜单**启动 lebi-AI。
5. 若系统提示安装 **WebView2** 运行时：点允许，等待联网自动安装完成（仅首次）。

## 4. 首次使用（两平台相同）

1. 首次打开会进入**三屏引导**：开场 → 选你主要在哪些事上需要它搭把手（可多选，可填称呼）→「开始干活」。
2. 没有配置 API Key 时会先进入**设置**：在下拉框里**选择模型服务商**（默认 DeepSeek，推荐国内用户），地址和模型会自动填好，你只需要粘贴 **API Key**。
   - Key 只写入本机配置文件（macOS `~/.lebi-ai/config.toml`，Windows `%USERPROFILE%\.lebi-ai\config.toml`，权限 600），不上传任何第三方。
   - 你也可以在「设置」页随时**切换服务商或换 Key**，点保存后**立即生效**，无需重启。
   - **未配置 Key 前无法发起对话**：在对话页发送消息会被提示并跳回设置页；配置好后即可正常使用。
   - 不知道怎么获取 Key？设置页 API Key 输入框下有**内嵌教程**（一键打开所选服务商官网）；完整图文版见 [`api-key-guide.md`](./api-key-guide.md)。
3. 回到**对话**页，开始共事——可以直接说「帮我把下周要干的事排个优先级」。

> 如果你也装了命令行版（`hermes`），也可以先跑 `hermes init` 完成同样的配置，两边共用同一份配置。

## 5. 你的数据都在哪

所有数据都在本地一个目录里，全部是**明文文件**（Markdown / JSONL），随时可读、可备份、可进 git：

| 平台 | 数据目录 |
|------|----------|
| macOS | `~/.lebi-ai/`（即 `/Users/<你的用户名>/.lebi-ai/`） |
| Windows | `%USERPROFILE%\.lebi-ai\`（即 `C:\Users\<你的用户名>\.lebi-ai\`） |

主要内容：

- `config.toml` — 模型服务商与 API Key（权限 600）
- `sessions/` — 每次对话的完整记录（JSONL）
- `memories/` — 你批准沉淀的记忆（Markdown + frontmatter）
- `skills/` — 你批准沉淀的技能
- `reflect-log.jsonl` — 进化候选的确认/拒绝审计日志
- `commitments.json` — 在办
- `reviews/` — 回顾（周报底稿）

**备份 / 迁移 = 复制整个 `.lebi-ai` 目录**；换机器时拷过去即可，数据是自包含的。

## 6. 卸载

- **macOS**：把「应用程序」里的 lebi-AI 移到废纸篓；数据在 `~/.lebi-ai/`（是否删除由你决定）。
- **Windows**：设置 → 应用 → 找到 lebi-AI → 卸载；数据在 `%USERPROFILE%\.lebi-ai\`（是否删除由你决定）。

## 7. 升级

下载新版本安装包重新安装即可，`~/.lebi-ai`（或 `%USERPROFILE%\.lebi-ai`）里的数据原样保留。

## 8. 文档导入（Word / PDF / Excel → 对话）

macOS 与 Windows 安装包都已内置转换器，把文件拖进对话即可。开发者本机可用环境变量 `HERMES_MARKITDOWN` 覆盖。

## 9. 常见问题（FAQ）

- **提示「已损坏，无法打开」？** 未签名应用偶尔被误报。先试右键 → 打开；仍不行就重新下载一份再试。
- **打开后白屏 / 打不开？** 确认是从安装包安装的完整版本；Windows 确认 WebView2 已安装（见第 3 节第 5 步）。
- **忘记 API Key 存在哪？** 设置页重新填写即可，不会影响已保存的对话与记忆。
- **换电脑怎么继续用？** 把旧的 `.lebi-ai` 目录整体复制到新机器同名位置，启动后数据即恢复。
- **手机上能用吗？** 可以：本机运行 `hermes serve` 后，用配套移动客户端连接（见 README「消息渠道」）。桌面、手机、微信、飞书、Telegram 共用同一份数据。

# 获取 API Key 教程（用户向）

> **种类：** B 用户说明书（非权威）。冲突以 P0 v0.9 为准。
> 对话能力来自你选择的模型服务商，需要自备 **API Key**。数据默认在本机。
> 桌面应用另有试用/授权（与模型账单不是一回事）。

---

## 1. 为什么要 API Key？

- lebi-AI 是一个**本地应用**：它不运营模型，而是调用你选的模型服务商（类似「水电公司」）。
- **API Key 是你在这个服务商的凭证**（相当于「账号 + 密码」合体的一串字符，通常以 `sk-` 开头）。
- 它**只保存在你本机**（`~/.lebi-ai/config.toml`），lebi-AI 不会上传，也不会替你做任何扣费决定。

## 2. 要花钱吗？

| 服务商 | 计费方式 | 国内支付 |
|--------|----------|----------|
| DeepSeek | 按用量计费，很便宜（百万 token 级定价，几元到几十元），新用户常有免费额度 | ✅ 支付宝/微信即可充值 |
| Anthropic（Claude） | 按用量计费，质量高、价格偏高 | ❌ 需海外支付方式（外币卡） |
| OpenAI 及兼容服务（智谱、Kimi、Qwen、OpenRouter 等） | 各家不同，多数按量计费 | 部分国内可用（如智谱/通义），OpenAI 官方需外币卡 |

> 结论：**国内用户从 DeepSeek 开始最省事**（便宜、支付宝充值、还提供 Anthropic 兼容接口，lebi-AI 里可以直接选「Anthropic 协议 + DeepSeek 地址」）。

## 3. 具体怎么拿（三步）

### 3.1 选一家服务商

按上面表格选一家即可。首次建议 DeepSeek。

### 3.2 去官网注册并创建 Key

| 服务商 | 官网 | 创建 Key 的位置 |
|--------|------|----------------|
| Anthropic | <https://console.anthropic.com/> | 登录 → Settings / API Keys → **Create Key** |
| DeepSeek | <https://platform.deepseek.com/> | 登录 → API Keys → **创建 API Key** |
| OpenAI | <https://platform.openai.com/api-keys> | 登录 → API keys → **Create new secret key** |

通用步骤（以 DeepSeek 为例）：

1. 打开官网，用手机号/邮箱注册并登录（新用户一般有免费额度）。
2. 左侧或顶部菜单找到 **API Keys**（有的叫「密钥管理」）。
3. 点 **创建 / Create**，按提示命名（随便起，如 `lebi-ai`），系统会生成一串以 `sk-` 开头的 Key。
4. **立即复制保存**——很多平台创建后只显示一次，关掉就看不到了。

> 各平台页面会迭代，若入口名称不同，在官网里找「API Keys / 密钥 / 令牌」等字样的页面即可，**以官网当前页面为准**。

### 3.3 填进 lebi-AI

1. 打开 lebi-AI → **设置**（或首次引导里点「连上你的 AI」）。
2. 在**模型服务**下拉框选择服务商（默认 DeepSeek，推荐国内用户），地址和模型自动填好。
3. 把 Key 粘贴到 **API Key** 输入框，点 **保存**——立即生效，无需重启。
4. 回到对话页，说一句「你好，帮我写一份项目计划」试试。

## 4. 安全须知（重要）

- **API Key 相当于密码**：不要发到群里 / 朋友圈 / 代码仓库；不要截图发别人。
- 只在 lebi-AI 设置页或你自己的配置文件中使用。
- 如果怀疑泄露：去服务商官网 **作废（Delete）该 Key 并新建一个**，然后在设置页换上新的 Key。

## 5. 常见问题

| 问题 | 回答 |
|------|------|
| 填了 Key 但对话还是失败？ | 检查 Key 是否复制完整（以 `sk-` 开头、无空格）；检查「高级设置」里的地址/模型是否被改过 |
| 想换一家服务商？ | 设置页下拉选择即可，地址和模型自动带出；不同服务商的 Key 不通用，需在官网另办 |
| 同一个 Key 能同时用于手机和电脑吗？ | 可以，Key 是服务商侧凭证，多设备共用（用量合并计费） |
| 忘记 Key 了怎么办？ | 服务商官网重新创建一个即可，旧 Key 不用管（可作废） |
| lebi-AI 会拿我的 Key 去别的地方吗？ | 不会，Key 只写在本机配置文件，仅用于调用你配置的模型服务商 |
| 为什么保存后立即就能用？ | 保存时应用会直接切换为新服务商和新 Key，无需重启；若仍失败，检查 Key 是否正确复制 |

## 6. 进阶

- 命令行用户：`hermes init` 可以交互式完成同样的配置（与 GUI 共用 `~/.lebi-ai/config.toml`）。
- 想用多种模型：在设置页下拉切换服务商即可；「高级设置」里也可以改模型名（如 DeepSeek 的 `deepseek-reasoner`）。
- 开发者/测试者可用 `LEBI_DATA_DIR` 指定独立数据目录做干净环境验证。

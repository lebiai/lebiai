## 0-fp. 第一性原理（必填 · P0 第零条）

- **拒绝的类比：** 不是「界面上还有个小字没删掉」（那是把症状当根因）；不是「把 `seconds` 留成兼容字段更稳」（兼容一个没人能写的字段，等于留一条走不到的路）。
- **拆出的真：**
  1. **「秒」这个量已经不属于任何一棒了。** 节目时长（数字人与成片）在系统外，这一期的终点是**书面稿**（B 批）。吕老师被裁定与时间无关，小宋不读秒数 —— 于是**没有任何一环能产生 `seconds`**。
  2. **留着读不到的字段，坏处不是「占几行代码」，是它会被当成能力。** 模型从 schema 里看不到它，但契约、夹具、界面还在演它：界面上留着一个「40s」的渲染分支，读的就是一条永远为 `None` 的字段 —— **死枝**。
  3. **旧文件得能读。** 已经有落盘的选题单里写着 `seconds: 40`（用户手改过的也算）。撤字段不能把旧文件读废 —— 那条文件头读不出来，界面就会把它当**普通产物**，用户会以为自己的选题单没了。
- **如何从真推出：**
  ① 把 `seconds` 从**整条链**上撤下来：引擎 `Item` → 工具说明 → GUI 视图 → TS 类型 → 渲染 → i18n 文案，一处不留；
  ② 旧文件靠 serde 的**默认宽松**（未知字段忽略）继续可读，并**加一条测试钉死**（这正是「撤字段」与「读得回来」的分界）；
  ③ 契约里能教出旧格式的地方（索引示例多一列、红线里的旧等级词）一起清。

## 0. 用户价值（必填 · 站在用户角度）

- **谁用：** 在项目组（财富早知道）或工位里点头的人；以及以后要接手这块代码的人。
- **解决什么痛点：** ① 卡片上那行「40s」是个永远不出现的影子，用户看不到、也不知道它本该是什么；② 契约里三处对「概要能不能只凭列表页」说法不一，模型执行哪一条全看运气；③ 索引示例多一列旧等级 —— **照着抄就会生成六列索引**，下游按 ID 取料直接失配。
- **用完后用户多得到什么：** 卡片上只剩「这一条是什么」和「为什么播它」两样**真的存在**的信息；契约里同一件事只有一个说法。
- **好用性自检：**
  - [x] 不需要额外运行时 / 数据库
  - [x] 步骤可感知、可预期（界面少一个影子元素，其余不变）
  - [x] 不增加无意义确认或噪音
  - [x] 主操作一眼能找（点头卡没变：标题 + 条目 + 为什么 + 按钮）
  - [x] 高频路径更干净（契约里冲突消失）

## 0b. 产品经理视角（必填 · 禁止跳过）

- **场景：** 吕老师报题 → 界面上出一张待点头卡 → 用户看条目、点头（或要改）。
- **怎么走完：** 卡片列标题与条目（每条一行字）→ 下面一行「为什么」→ 按钮。**条目那一行不再有秒数**；用户要看配速的话，那是小宋成稿那一棒的事，不在这张卡上。
- **看起来怎么样：** 每一条就是 `1. 央行开展 5000 亿 MLF`；不再有「40s」这种既点不动、也不解释的角标。
- **好走 / 好看：** 卡片信息密度降一档，一屏能看全；不用猜那个数字是什么。
- **成功标准：** 界面上搜不到秒数；旧选题单（带 `seconds:`）照样出卡、状态照样读得对。
- **明确不做什么：** 不动卡片的其余部分（状态、谁定的、为什么、按钮）；**不改历史文件**；不给小宋补一个「配速」字段。

## 0c. 架构师视角（必填 · 禁止修修补补）

- **根因层级：** 定义层 —— `seconds` 是**节目时长时代的残留字段**，它的生产者（吕老师）与消费者（小雨的口播）都已经不在这一期里；字段本身成了定义上的孤儿。
- **正确的长期默认路径：** 决定的 `items` 只有两样：`title`（进什么）+ `note`（为什么）。旧文件由 serde **未知字段忽略**兜住（不写 `deny_unknown_fields` —— 那是给编译进二进制的定义用的，用户能改的文件一律柔性降级，见 `decision.rs` 模块注释）。
- **与引擎/各入口边界：** 只动视图层与说明文字；CLI / channel / server 本来就不读这个字段（实测全仓只有 GUI 一条链）。
- **安全影响：** 无。
- **如何防复发：** ① `persona.rs` 里已有「吕老师契约不许出现 `秒/配速/时长/分钟`」的断言（本批复核仍然成立）；② 本批新增旧文件兼容测试；③ 工具的 `input_schema` 早在 A 批就撤了 `seconds`，本批把**说明里那句否定句**也删掉（提一句就是给模型一个念头）。
- **为何这不是补丁：** 是把一整条**没人能写、也没人该读**的链从定义层撤掉，不是给界面加个 `if` 藏起来。

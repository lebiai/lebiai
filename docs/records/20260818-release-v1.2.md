## 0-fp. 第一性原理

- **拒绝的类比：** 不是另起发版流程；不是在发布说明里把「点更新」写成已经能用。
- **拆出的真：** 更新器必须先装进应用，再发一版，概览才会出现「更新」。这一版是带更新器的安装包。
- **如何推出：** 升 1.2.0；说明写清「这一版带更新器，下一版才能点」；推 main + `v1.2.0`。私钥不进 git，走 Actions secrets。

## 0. 用户价值

GitHub 可下 1.2 的 dmg / exe。装上之后，设置概览能看见版本；再往后的版本可以在设置里点更新。

## 0-fp. 第一性原理（必填 · P0 第零条）

**拒绝的类比：**「发现问题就往契约里再补一句提醒」。这个类比的错处是：它假设病在「模型忘了」，
于是把力气花在**把话再说一遍**上。真正要从头推的是：**这两件事为什么会对用户造成可见的错。**

**拆出的真（两件事，两处真）：**
1. **角度列带进素材外的数字** —— 用户买单的是「能核」。吕老师交给下一棒的是 **ID**，小宋拿 ID
   回原文取料。所以「角度」这一列一旦写了取不回来的数字，下一棒**必然核不上**，用户看到的是
   两个人物互相打架。这不是措辞问题，是**契约没写死哪一列是什么料**：角度列是**判断**，
   不是**引用**。
2. **CLI 里 `decision` 记不了决定** —— `decision` 判定「谁定的」靠的是引擎盖的章（`Stamp`），
   模型给不了。GUI 盖了，CLI 没盖。**同一个引擎、同一份真相，两个入口各判一次** —— 一处漏判，
   就是「在这个入口里这条契约根本走不通」。这不是 CLI 缺功能，是**接线不一致**。

**如何从真推出做法：**
1. 角度列写死「只写角度，不写素材外的事实与数字；要写数字必须能指回取回来的那三行，指不出就不写」，
   并在守卫里断言这句在。
2. CLI 补上与 GUI **同一层、同一判据**的 `StampedHost`：有人物才盖，没人物不盖（工具照旧明说记不了）。
   两处读同一个 `speaker`，不各判一次。

**为什么不在工具里放宽：** 放宽「谁定的」= 允许一份决定缺掉四样里的一样，等于把用户要的可追溯性丢掉；
真正的病在装配链，堵在工具上就是叠补丁。

## 0. 用户价值（必填）

- **发现 1**：用户不会再看到「吕老师写了、小宋核不到」的对不上。角度列从此是**判断**，
  事实与数字一律回到原文——用户真要追一个数字，追得到出处。
- **发现 2**：在 CLI 里跑项目组流程（我们自己的验证/调试入口）时，`decision` 不再恒被拒。
  用户默认路径是 GUI，这条**不改用户可见面**，改的是「调试入口和真实路径走同一份真相」——
  否则我们每次在 CLI 里验证，都在验一个和 GUI 不同的东西。

## 0b. 产品经理视角（必填）

- **用户怎么走完**：用户看不到任何新按钮、新步骤。他在 GUI 里照旧点头、照旧看《选题单》。
  差别在《选题单》的「角度」列不再冒出原文里没有的数字。
- **看起来怎么样**：《选题单》还是 `序号｜ID｜秒数｜角度` 四列 + 一行一条台账，**格式一字未改**；
  变的是角度列的**内容纪律**。
- **空 / 载 / 错态**：角度列指不出出处的数字 → **不写**（宁可少写，不写错）；CLI 里没人物 →
  `decision` 照旧明说「记不了」，不是静默瞎填。
- **成功标准**：① 吕老师契约里「角度列不许带素材外事实」这句在，且有守卫；② CLI 里有人物时
  `decision` 能落盘，且 `by` 是该人物 id。
- **不做什么**：不改《选题单》格式；不给用户加操作；不动 GUI 那一层（本来就是对的）。

## 0c. 架构师视角（必填 · 禁止修修补补）

- **根因（两处，各自一处）**：
  - ① 契约只写了「角度」是什么，没写**它不是引用**；
  - ② CLI 的 host 装配链少了 `StampedHost` 这一层（GUI 有）。
- **正确默认路径**：
  - ① 在 `lv-lao-shi.md` 里把角度列的**料性**写死（判断，不是引用），配守卫；
  - ② 在 CLI 的装配链里、`SessionRecallHost` 之外补 `StampedHost`，判据与 GUI 逐字同构
    （`speaker` 取自 `persona::speaker_for`，`team` 与 `episode` 同源）。
- **边界**：`speaker` 在 CLI 里**只算一次**，记忆归属（`memory_owners_for`）与盖章读同一个值——
  两处各判一次就是下一个「发现 2」。
- **不做**：不改工具层的拒绝语义；不把 CLI 变成第二条产品路径。

## 1. 方案（Design）

1. **吕老师**（`lv-lao-shi.md` 0.3.0 → **0.3.1**）：
   - 「我干什么」第 2 条补：**角度列只写角度，不许带进索引和取回那三行里没有的事实与数字**；
     要写数字必须能从取回来的那三行里指出原话；指不出就只写角度、不写数字。
   - 「我的口径」补一条同义的口径句（「角度列不许有『素材外』的事实」）。
2. **守卫**（`persona.rs`）：在 `the_pipeline_hands_over_ids_and_an_index_not_whole_files` 里
   对吕老师追加断言，缺「角度列」「指不出」即失败。
3. **CLI 接线**（`hermes-cli/src/commands/chat/mod.rs`）：
   - 把 `speaker`（`persona::speaker_for`）提到 `owners` 之前，**一处算、两处用**；
   - 在 `SessionRecallHost` 之外补 `StampedHost`，`by` / `team` / `episode` 与 GUI 同源。

### 不做
- 不动《选题单》与成品格式；不动 GUI；不放宽 `decision` 的拒绝语义。

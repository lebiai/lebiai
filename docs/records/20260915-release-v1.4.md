## 0-fp. 第一性原理

- **拒绝的类比：** 不是把十几天的改动塞进 1.3 的包；不是在说明里写没实现的能力
  （侧栏增删改人物、一键切按钮、输入框提示语跟着人物变——这三条 1.4 都没有）。
- **拆出的真：** 1.3 之后的工作树里躺着一整层新东西（人物/工位、记忆主题卡、材料分页、
  产出按天归位、安静失败、安全加固），它们已经互相依赖、不能只挑一半发；客户要的是
  **一个能装、能验授权、能看见工位的包**，那就必须换版本号、换说明、换 tag。
- **如何推出：** 升 1.4.0（四处对齐 + lockfile）→ 重写 `docs/releases/release-notes.md`
  （只写本版真有，并把「明确没做」列出来）→ 推 `main` → 打 `v1.4.0` → `release.yml`
  在 macos-14 / windows-latest 上产出 dmg / NSIS setup.exe 并挂 Release。

记忆各归各的。安装包在 GitHub 可下；1.3 用户可在设置里点「更新」升上来。

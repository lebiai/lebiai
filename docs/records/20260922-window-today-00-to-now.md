## 0-fp. 第一性原理（必填 · P0 第零条）

- **拒绝的类比：** 不是「把 06:00 改成别的钟点」（换钟点治不了病：病在**窗口依赖上一期**）；不是「兜底窗口再兜一层」（`FALLBACK` 是「我们不知道」，而用户要的是「一定知道」）。
- **拆出的真：**
  1. **用户问的是「今天的新闻」，不是「上一期之后的新闻」。** 窗口的语义由**用户的问题**决定，不由出刊节奏决定。上一期 06:00 → 这一期 06:00 是**为连续出刊设计的**，一旦没有上一期（新装、清空、断更），它立刻退化成「0 点到 6 点」——一个用户看不懂、也答不出他问题的窗。
  2. **窗口的两端都应该是「跟用户有关的事实」**：起点 = **今天开始**（用户的「今天」），终点 = **我按下采集那一刻**（用户正在问的时点）。两端都不依赖历史、不依赖钟点、不依赖上一期。
  3. **推断出来的东西必须留痕 → 现在不需要留痕了。** `FALLBACK_TIME_WINDOW` / `COVERAGE_GAP` 是旧窗口的补丁：前者标「T_prev 是推的」，后者标「两卷之间可能漏了」。窗口不再链接上一卷，这两个标记连同它们的产物行**整体失去意义**——留着就是死代码。
- **如何从真推出：**
  ① 契约里窗口写成一条：`[今天 00:00, 现在)`，两端各一句（起点 = `date +%F` 的 00:00；终点 = `date '+%H:%M'`）；
  ② 卷首第一行照它写；子代理工单发的仍是**起止两个时刻**（机器判定不变）；
  ③ 撤掉 `T_prev`/`T_current`、`FALLBACK_TIME_WINDOW`、`COVERAGE_GAP` 与「卷间衔接」整段（契约定稿准则：不留史、不留死枝）；
  ④ 「近 3 天」保留为**唯一的覆盖入口**（用户要更宽时明说）。

## 0. 用户价值（必填 · 站在用户角度）

- **谁用：** 喊「海燕，采今天的资讯」的人。
- **解决什么痛点：** ① 历史一清空（或第一次装），窗口就退化成「今天 00:00 — 06:00」，下午跑等于**把当天绝大多数新闻丢掉**；② 卷首挂的 `FALLBACK_TIME_WINDOW` 和文末「卷间衔接 N 小时」是给工程看的词，用户只想知道「这是今天的东西吗」。
- **用完后用户多得到什么：** 任何时刻喊一声，拿到的都是**今天从 0 点到此刻**的全量；下午三点跑就采到三点。
- **好用性自检：**
  - [x] 不需要额外运行时 / 数据库
  - [x] 步骤可感知、可预期（早上跑采到早上，下午跑采到下午）
  - [x] 不增加无意义确认或噪音（少了两行工程味的话）
  - [x] 主操作一眼能找（不变）
  - [x] 高频路径更干净（窗口不再依赖 `outputs/` 里有没有上一期目录）

## 0b. 产品经理视角（必填 · 禁止跳过）

- **场景：** 用户在财富早知道里喊一声「采今天的资讯」→ 王海燕派六个子代理并发采 → 交一份资讯卷。
- **怎么走完：** 第零步一条 `bash` 算出窗口 → 写进六份工单 → 六个子代理各自落块 → 一条 `bash` 接栏、去重、补统计、编索引。
- **看起来怎么样：** 卷首第一行从 `窗口 2026-09-21 06:00 — 2026-09-22 06:00（北京时间）｜FALLBACK_TIME_WINDOW` 变成 `窗口 2026-09-22 00:00 — 2026-09-22 16:58（北京时间）`；文末「卷间衔接」那一行整条消失，只剩一行采集统计。
- **好走 / 好看：** 用户扫一眼卷首就知道「这是今天 0 点到刚才的东西」。
- **成功标准：** 契约里搜不到 `06:00`/`T_prev`/`FALLBACK_TIME_WINDOW`/`COVERAGE_GAP`；实跑卷首两端的日期**都是今天**、终点是当刻。
- **明确不做什么：** 不动六个分块、不动信源层级、不动三行条目格式、不动索引 5 列与 ID 规则、不动「近 3 天」覆盖入口。

## 0c. 架构师视角（必填 · 禁止修修补补）

- **根因层级：** 定义层 —— 旧窗口把「这一期该采什么」定义在**上一期**上（`T_prev` 由 `outputs/` 目录名推出），于是窗口的语义依赖于**历史是否存在**，而历史是可以被清空的外部状态。
- **正确的长期默认路径：** 窗口只依赖两个**当场可测**的事实 —— 今天 00:00（`date +%F`）与按下采集那一刻（`date '+%H:%M'`）。零推断、零兜底、零状态。

## 5. 附注

- **实跑输出（临时工作区，三个块各 1 条）：**
  - 卷首：`# 财富早知道 · 资讯卷｜窗口 2026-09-22 00:00 — 2026-09-22 16:58（北京时间）`
  - 统计行：`本次采集统计：有效资讯 3 条（官方 1／主流 1／其他 1；进正文写概要 3 条；另有 1 个站点本轮拿不到；格式不合规丢弃 0 条）。`

- **为什么不要「上一期之后」这个语义：** 它把窗口的跨度交给**出刊节奏**（周末就跨三天）；用户问的是「今天」，不是「上一期之后」。要更宽，用户会说「近 3 天」。

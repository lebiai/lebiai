## 0-fp. 第一性原理

- **拒绝的类比：** 不是做 Notion/RAG/律师知识库；不是先做网盘再接线。
- **拆出的真：** 普通人只对话、丢文件；成功是答里用上自己的材料；记忆与材料是两类对象；假命中比漏检更伤；开口不能读每一份文件。
- **如何推出：** 种类 G 把「做什么 / 怎么做 / 傻瓜默认 / 全坑」一次写全；用户面零技术词；未升 P0 不改代码。

## 0. 用户价值

协作者有一张完整地图，避免做成能逛的库或每轮扫盘。用户在立项前无感知变化。

## 0b. 产品经理

- **场景：** 桌面对话为主；材料后场。
- **怎么走完：** 打开即对话 → 丢文件当次能用 → 值得留的点「留下」或嘴上说留下 → 下次直接问 → 一句出处。
- **看起来：** 不新增顶栏；劝留一条不挡输入；空库与今天无异。
- **不做什么：** 不升 P0；不实施；不把「蒸馏/向量」交回给用户出题。

## 0c. 架构师

- **根因：** 需求曾混称知识库；讨论散落在会话。
- **默认路径：** 新对象 `sources` + 收下建索引 + 每轮内存检索 + 注入可剥除。
- **为何不是补丁：** 先立法对象与傻瓜默认，再允许开工。

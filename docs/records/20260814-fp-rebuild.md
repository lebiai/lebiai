## 0-fp. 第一性原理

- **拒绝的类比：** 打开先选会话（ChatGPT）；编程 Agent 系统提示（Cursor/Claude Code）；离开就弹 Reflect；侧栏 MCP/权限 DSL；`ask` 默认 YOLO。
- **拆出的真：** 用户打开桌面是来共事；搭子不替你做完；进化须点头；代码偶发；看得见的要好走好看；无确认面不能当 root。
- **如何推出：** 打开即对话；离开只进「待你点头」；共享提示是共事不是改代码；默认壳去掉调试台；CLI run/ask 是引擎模式。

## 0b. 产品经理视角

- **场景：** 打开 GUI 开始做事；离开对话；在 IM/CLI 说话。
- **怎么走完：** 打开 → 已在对话里 → 写/点场景卡；离开 → toast 说记忆里有待确认，点记忆去确认。
- **看起来怎么样：** 主界面是对话；过程区人话；无 token、无 MCP 导航。
- **成功标准：** 无需再点「新对话」才能输入；文案不承诺弹窗；模型不被训练成先 grep。
- **不做什么：** 不重做全部设置页；不删引擎工具实现。

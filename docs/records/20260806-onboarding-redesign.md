## 0. 用户价值（必填 · 站在用户角度）

- **谁用：** 终端客户 —— 每人一台电脑、无技术背景、安装打包好的 dmg。
- **解决什么痛点：** 现引导页把「本地明文、进化需批准」当卖点，客户无感；「开始」与「跳过」功能等价；介绍的是产品边界而非「它能帮我干嘛」，客户看完不知道这玩意能干活。
- **用完后用户多得到什么：** 30 秒内明白「这是给我干活的搭档」；选完工作场景后，欢迎页按他的场景排卡片，**第一次进对话就感觉被定制**（「越用越像你的手感」的第一次体感）。
- **好用性自检：**
  - [x] 不需要额外运行时 / 数据库
  - [x] 步骤可感知、可预期（三屏，每屏一件事）
  - [x] 不增加无意义确认或噪音（信息全选填；跳过即白纸进入）
  - [x] 高频路径比改前更快（客户从「读道理」变为「选战场→直接干活」）

---

## 0b. 产品经理视角（必填 · 禁止跳过）

- **场景：** 客户首次打开 dmg，无任何技术背景，30 秒内决定「这值不值得我用」。
- **路径变化（目标路径 · 已由用户确认）：**

```
屏1 开场：大标题「上班，多了一个能扛事的搭档」+ 副标题「接得住你的想法，推得动你的事——而且越用越懂你」
        + 「你可以这样说」演示卡（预置「帮我把下周要干的事排个优先级」）
        + 一行轻信任感小字（非技术词）
屏2 选战场：问「你主要在哪类事上需要它搭把手？」5 张场景卡多选（写东西/想清楚/查资料/盯进度/其他）
        + 「别人怎么叫你？」（选填）
        + 选完反馈「记住了——以后默认按你这种方式陪你干活」
屏3 开场：主按钮「开始干活」（保存称呼+场景 → 进对话；无 Key 时先引导配置）
        + 次按钮「先随便看看」（不保存，直接进）
```

- **CTA 差异（明确）：** 「开始干活」= 保存画像进对话；「先随便看看」= 白纸进入。不再等价。
- **成功标准：** 客户三屏走完能说清「这工具能帮我写方案/理思路/盯进度」；选过的场景在欢迎页卡片**排前面**；引导页**不出现微信**（设置页保留）；第一次对话带上称呼与场景上下文。
- **明确不做什么：**
  - 不做账号体系 / 云端画像 / 大问卷
  - 不做多语言扩展（仍 zh-CN/en-US）
  - 不做敏感信息收集
  - 微信不再出现在引导页（仅设置页）

## 0c. 架构师视角（必填 · 禁止修修补补）

- **根因层级：** 首启体验与入口设计层。现有引导 = 价值说教 + 零收集 + CTA 等价，未利用引擎已有的 pinned memory / profile 上下文能力。
- **正确的长期默认路径：**
  1. **引导 = 认识 → 场景 → 开始**：三屏状态机，收集最小信息（称呼 + 工作场景），全部选填。
  2. **单一事实落盘**：称呼 + 场景写为**一条 pinned memory**（`source: user`，`pinned: true`，tag `onboarding-seed` + 场景 tag）——引擎 `ServeCtx` 已加载 pinned memories，第一次对话即带上下文；用户可在记忆侧栏查看/删除。
  3. **欢迎页从同一事实派生**：`WelcomeScenes` 四卡重构为工作场景卡（写东西/想清楚/查资料/盯进度），新 command `onboarding_seed_get` 读取 seed 排序，未选场景排后——不另存 UI 副本（无双重状态）。
  4. **微信入口收敛**：引导页移除微信；设置页 `WechatConnectCard` 不动。
- **与引擎/各入口边界：** 引擎零改动（复用 GUI 现有 `create_memory` 落盘路径）；新增 2 个薄 command（`onboarding_seed_set` / `onboarding_seed_get`）；CLI / server 不受影响。
- **安全影响：** 无新风险。称呼/场景非敏感，本地明文 memory，可改可删；不新增出站。
- **如何防复发：** 欢迎页与引导页共用场景定义（同一常量表 + i18n）；「引导页塞渠道入口」在开发规则上明确禁止（渠道入口只放设置页）。
- **为何这不是补丁：** 把「说教式首启」重做为「认识客户 → 定制首屏」的正确默认路径，并复用引擎既有上下文能力，不是临时特判。

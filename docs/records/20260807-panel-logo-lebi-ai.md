## 0c. 架构师视角

- **根因层级：** 品牌资源只在打包层（Tauri icons）就位，UI 层侧栏品牌位仍是代码占位图标，未接入品牌资源
- **正确的长期默认路径：** 品牌图作为前端资源进 `ui/src/assets/`（与 Tauri icons 同源：由 `icons/lebi-master.png` 母版生成），侧栏直接引用；删掉占位的 lucide `Hexagon` 导入（凡旧必清）
- **与引擎/各入口边界：** 只动 `crates/hermes-gui/ui`（Sidebar.tsx + assets + vite-env.d.ts）；Rust/引擎/server/CLI/Flutter 零改动
- **安全影响：** 无
- **如何防复发：** 品牌位统一引用 `ui/src/assets/logo.png`；`rg Hexagon` 归零；母版改版时同步再生成 Tauri + Flutter + ui 资源
- **为何这不是补丁：** 品牌资源收敛为「母版 → 各端生成」单一事实源，UI 占位图标是最后的遗漏点，本次补齐

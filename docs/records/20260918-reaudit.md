## 0-fp. 第一性原理

- **拒绝的类比：** 不是「上轮已经扫过一遍，这轮挑几条确认一下」；不是「子代理说有就有」；不是「文件里写着的就算做完了」。
- **拆出的真：**
  1. 审查结论只有两种状态：**我亲眼在源码/数据/线上核对过**，或**明确标注未核实**。中间态（看起来像真的）必须消掉。
  2. 「文档写了 / 注释写了 / 落地表打了勾」都不是实现。说明书与实现相反时，两个都要改，不能只改一个。
  3. 数据根、密钥、发布链三类东西一旦错了，用户不会在界面上看见，只会在某天付出代价。
- **如何推出：** 五个互不依赖的域各派一个只读代理，要求「每条给 file:line + 原文、标亲验/推测、按 P0/P1/P2 分级」；主线自己跑门禁、亲验 P0 与关键数字，并**修正**上一轮对不上的数字。

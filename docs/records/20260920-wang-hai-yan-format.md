## 0-fp. 第一性原理

- **拒绝的类比：** 不是「一行塞到底的列表」（读不动）；也不是「**资本市场（28 条）** 七件 A 级：…」
  这种把清单压成一段的摘要卷（用户的原话：**都罗列在一起我怎么看呢？新闻出处呢？**）；
  更不是「让界面自己去猜哪里该换行」。
- **拆出的真：** 用户要的是一条一条**看得见**的资讯：等级、来源、时间、完整概要、原文链接，
  五样都在明面上；而且**对话里看到的就得是这份清单本身**——不是文件里有、对话里没有。
  另外两条真：站点异常与待核**不是这次要看的读物**（异常只值一个数字，待核跟着那条走）。
- **如何从真推出：** 条目按用户选定的三行块写（等级·来源·时间 / 概要 / 链接）+ 条间空行；
  删掉【站点异常】【待核项】两节；对话与文件逐字一致。
  渲染层必须补 `remark-breaks`——否则三行在 GUI 里会被折成一行，用户看到的仍是一坨。

## 0b. 产品经理视角

- **场景：** 用户说「干活」→ 王海燕跑完一轮 → 用户要在对话里读这份卷子。
- **怎么走完：** 三栏固定（宏观 / 产业动态 / 资本市场）→ 栏内 A → B → C、同级按时间倒序 →
  每条三行块、条间空一行 → 文末一行统计 → 落盘 `outputs/<日期>/资讯-<日期>.md`，对话逐字同款。
- **看起来怎么样：**
  ```
  【A】新华财经｜2026-09-20 09:27｜
  央行公布9月贷款市场报价利率（LPR）：1年期3.0%、5年期以上3.5%，均维持不变，为连续16个月按兵不动。｜
  https://www.cnfin.com/kx/detail/20260920/4472251_1.html
  ```
- **好走 / 好看：** 等级一眼可见、来源与时间在首行、链接单独一行；长概要不再把行撑爆。
- **成功标准：** 用户只读对话就能判断「这条我要不要」，不必打开文件。
- **明确不做什么：** 不另开【站点异常】【待核项】节；不在时间栏写「发布时间：」；
  不拆多份文件；不做投资建议。

## 0c. 架构师视角

- **根因层级：** 两处。① 提示词层：帽子只写「对话里给摘要」→ 模型合理地交了一段散文；
  ② UI 渲染层：`MarkdownContent` 只挂 `remarkGfm`，**单换行被折成空格**——
  三行格式若不加处理，界面里仍是一行。两者都要修，只修一处都是假修。
- **正确的长期默认路径：** 格式写进帽子（定义 = 单一真源），并由测试钉住；
  渲染层按「对话里单换行就是换行」办事（`remark-breaks`），不靠模型在行尾补看不见的空格。
- **与引擎/各入口边界：** 只改 `hermes-core` 的帽子与 GUI 的渲染插件；
  CLI / server / IM 不加平行逻辑（它们读同一份定义；IM 侧本就不走 ReactMarkdown）。
- **安全影响：** 无。`npm install remark-breaks` 只进前端构建。
- **如何防复发：** `wang_hai_yan_hands_over_a_gradable_brief_not_thirty_titles` 扩成格式契约——
  三行格式、对话逐字一致、「不许压成」、且**正文里不许出现【站点异常】【待核项】两节**。
- **为何这不是补丁：** 改的是「长什么样」的单一真源与它的渲染前提，不是给某次输出打码。

## 2. 实施（Implement）

- **实际改动摘要：**
  1. 帽子：条目改成用户选定的**三行块** + 条间空行；第一行只有等级·来源·时间（不带「发布时间：」）；
     第三行只放一个链接；拿不准的写进条目（句尾「（待核：原因）」）；
     **删掉【站点异常】与【待核项】两节**，失败站点只进文末统计的数字；
     **对话里就是这份清单本身、与文件逐字一致**；只落一个名字 `资讯-<日期>.md`；
     红线加「不准把清单压成摘要段」「不准另开那两节」；
     另加大卷分段写（先 `write` 骨架再 `edit` 补——上一轮两次 `write` 撞输出上限的直接教训）。
  2. GUI：`remarkPlugins={[remarkGfm, remarkBreaks]}`。
  3. 测试：上面的契约写进 `wang_hai_yan_hands_over_a_gradable_brief_not_thirty_titles`。
- **关键路径/文件：** 见 §1。
- **偏离方案处：** 无。统计行保留（用户未反对），但不再点名失败站点。

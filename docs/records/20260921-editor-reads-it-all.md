## 0-fp. 第一性原理（必填 · P0 第零条）

**拒绝的类比：**「下游读得越少越快 —— 所以让吕老师也只看索引」。这个类比错在**把「读」当成了病**。
它假设瓶颈是**读入量**，于是上一批把「整读」一刀禁掉，吕老师只能拿索引里那半句线索判 180 条——
**判断依据被砍掉了**。用户一眼看出来：「你给了一点点内容，怎么判断呢？」

**拆出的真（实测，可核对）：**
- 上一批实测的病灶不是「读」，是**同一份东西被反复整读**：项目组会话
  `test/sessions/2026-09-20T07-38-43-a4a4d465.jsonl` 里 `资讯-2026-09-21.md` 被读 **16 次 ≈ 7.9 万字**；
- 而**整读一次**只要 **≈3.3 万字符**（728 行）。16 次 → 1 次，就已经省掉 **94%**；
- 这一棒的职责是**判全量**：180 条里哪条播、哪条不播、什么角度、多重 —— 这活的输入**必须**是
  每条的完整概要，否则判断无从谈起。索引的「线索」列实测**均 31.8 汉字**，只够认路，不够判。

**如何从真推出做法（三件）：**
1. **吕老师整读一次成品** —— 判全量是他的活，读一次是完成这活的**最小成本**；要禁的是**第二次**；
2. **索引的定位改口** —— 索引是**给小宋取料、给人翻目录**的（一条一个稳定 ID），
   **不是吕老师的筛面**；吕老师从索引只拿两样东西：**ID** 和 **L<行号>**（复核时用 `material_read`）；
3. **ID 改纯 ASCII** —— `<YYYYMMDD>-<lane>-<NNN>`，`lane ∈ {macro|industry|market}`。
   中文 ID（`资本-037`）是**机器和接力棒用的东西掺了中文**：BSD awk 是**字节语义**、
   **不认中文函数名**（实测 `function 线索(...)` 直接 `bailing out`），中文还会**按字节切半**。
   ID 只该由 awk 确定性生成、被 grep 精确匹配，掺中文就是给自己埋坑。

## 0. 用户价值（必填 · 站在用户角度）

- **谁用：** 财富早知道项目组里的用户（GUI 对话 / 项目组会话）。
- **解决什么痛点：** 上一批「治慢」治过头 —— 吕老师**只拿半句线索筛**，报出来的题没有依据、用户看不懂、
  也没法反驳；这一批把判断依据还给他，同时**不把慢放回来**。
- **用完后用户多得到什么：**
  - 吕老师报题时**真的读过每一条**（用户能对着成品核他的话）；
  - 读入量仍是**旧的 1/10 量级**（旧的病是 16 次重读，不是 1 次整读）；
  - ID 变成能放心交给 grep/awk 的纯 ASCII，接力棒不会因为中文编码在不同机器上对不上。
- **好用性自检：**
  - [x] 不需要额外运行时 / 数据库（仍是文件 + 明文）
  - [x] 步骤可感知、可预期（用户看到的操作步骤：**没变**）
  - [x] 不增加无意义确认或噪音
  - [x] 主操作一眼能找；空/载/错态完整（索引没落盘 → 吕老师必须明说并退回读素材）
  - [x] 高频路径步骤少、界面干净

## 0b. 产品经理视角（必填 · 禁止跳过）

- **场景：** 用户说「出这一期」，吕老师在项目组会话里报题。
- **怎么走完：** 用户**什么都没多看一眼**。终点仍是同一张《选题单》（`序号｜ID｜秒数｜角度`
  + 一行一条弃稿台账）。改的只有**盘面下的两处**：
  - 吕老师**读的东西变了**：从「只扫索引猜」→ **整读一次成品，逐条判**（用户要的正是这个）；
  - 他写出来的 **ID 长什么样变了**：`资本-037` → `20260921-market-037`（日期写在里面，
    用户和下游都不用再猜是哪一期）。
- **看起来怎么样：** 用户可见面**一个像素都没动** —— 选题单、成稿、索引三份文件的格式一字未改。
  索引里那列 ID 由中文栏名换成 ASCII 栏名，人一样一眼扫得懂。
- **空 / 载 / 错态：**
  - 索引没落盘 → 吕老师必须**明说「索引没落盘」**并退回读素材（不许假装扫过索引）；
  - `material_read` 说某条取不到 → 记一笔，这条按拿不准处理（**不编**）；
  - 素材里指不出出处的数字 → **只写角度、不写数字**（上一批收紧的规矩，本批保留）。
- **好走 / 好看：** 比上一批**更好走** —— 吕老师的报题有依据了，用户不用追问「你凭什么不要这条」。
- **成功标准：** 吕老师**整读一次**、判完全量、只交 ID；两次以上整读同一份文件 = 不合格；
  选题单体积仍是**个位/十位数 KB**；成品与选题单格式**一字不改**。
- **明确不做什么：** 不引数据库；不把索引塞给吕老师当筛面；不改成品格式（**ID 不进正文**）；
  不给用户加任何操作；不动上一批已定死的三行格式。

## 0c. 架构师视角（必填 · 禁止修修补补）

- **根因（我上一批的错）：** 把 **「读得少」当成了目标**，而不是问 **「这一棒的判断需要什么输入」**。
  慢的根因是**重复读**（同一文件 16 次），我却顺着「少读」这个方向把**整读**也禁了 ——
  等于把「判全量」这件事**从根上做不成**。这是**方向性错误**，不是参数没调好。
- **正确的长期默认路径（职责 → 输入 一一对应）：**
  | 棒 | 职责 | 该读什么 | 交什么 |
  |---|---|---|---|
  | 王海燕 | 采全、落盘 | 名单上的站点 | 成品 `资讯-<日期>.md` + **索引** `index-<日期>.md`（ID 纯 ASCII，由 `awk` 确定性生成） |
  | 吕老师 | **判全量** | **整读一次成品**；索引只取 ID 与行号 | 《选题单》：ID 单 + 弃稿台账（只交 ID，不搬正文） |
  | 小宋 | 按选题写稿 | **`material_read` 按 ID 取那几条** | 成稿 |
  | 小雨 | 播报 | **只读成稿那一份** | 口播稿 |
  **禁的是「第二次读同一个文件」，不是「读」。**
- **边界：**
  - 引擎**不截断** `read` 结果（会话里 `read` 一次回 37,428 / 17,466 字符都是完整的），也**不压缩**——
    所以「整读一次」在引擎层是**真的能读到**的，不靠运气。
  - 索引仍是**唯一**的 ID 来源，ID 由主循环 `awk` 生成，**不是模型随手编号**；`material_read`
    的栏名白名单同步改成 ASCII 三词（`LANES`）。
- **安全影响：** 无。数据仍本地明文，无新增网络/密钥/权限面。
- **如何防复发：** 契约里把两句话**写死并反向断言** ——
  ① 吕老师必须含「整读一次成品 / 读完不回头 / 不靠索引的线索列下判断 / 索引只给我 ID 和行号」；
  ② **反向断言**吕老师契约里**不许**再出现「禁止整读」（2026-09-21 中午那版留下的话，永久拉黑）；
  ③ 王海燕契约**不许**再说「吕老师筛选、小宋取料」；④ 王海燕必须含 ASCII ID 形状与三栏名；
  ⑤ `material.rs` 单测钉死中文栏名**一律拒**。
- **为何这不是补丁：** 治的是「**判断依据与职责错配**」这个根因（吕老师判全量 → 必须看见全量），
  不是给某一条报错加特判。三棒各自的输入与职责现在是一张能对上的表。

## 1. 方案（Plan）

- **目标：** 把吕老师的判断依据还给他（**整读一次成品**），同时不把「重复读」的慢放回来；
  素材 ID 改成纯 ASCII，让 awk/grep 的匹配跨机器可靠。
- **范围：**
  - **做：** 王海燕契约（ID 规矩 + 索引定位改口 + awk 栏名映射）、吕老师契约（取料节重写成 6 步）、
    `persona.rs` 守卫（改名 + 双向断言）、`material.rs`（`LANES` 白名单 + 单测改 ASCII）。
  - **不做：** 不改成品/选题单/索引**格式**；不引数据库；不动索引生成那段 `awk` 的**确定性逻辑**
    （只把 `k=宏观/产业/资本` 换成 `k=macro/industry/market`）；不动 GUI 可见面。
- **用户路径变化：** **无**（改前 → 改后，用户操作与看到的格式完全相同；只有 ID 的形状与
  「吕老师到底读没读」这两件事变了）。
- **技术要点：** `crates/hermes-core/src/personas/{wang-hai-yan,lv-lao-shi}.md`、`persona.rs`、
  `crates/hermes-tools/src/material.rs`。
- **风险与回滚：** 风险 = 整读回来 → 又慢。压法：契约 + 守卫把「**读完不回头**」写死，
  并实测取证（§3）。回滚 = 还原这 4 个文件（改动彼此独立、无数据迁移）。
- **方案确认：** [x] 已对照 P0/P1（含第七条）· 2026-09-21 · 用户当场拍板（「A」= 承认治过头，还他整读）

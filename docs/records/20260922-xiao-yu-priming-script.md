## 0-fp. 第一性原理（必填 · P0 第零条）

- **拒绝的类比：** 不是「口播稿就是成稿的缩写 / 换个说法」（把口播当**改写**，于是长度成了「跟成稿比」）；不是「时长是稿子的属性，写稿的人顺手就定了」（那是把**用户的取舍**塞给写手）。
- **拆出的真：**
  1. **口播稿是给耳朵听的第二个版本，不是成稿的压缩包。** 它的第一约束是**听多久**，而这个「多久」不是稿子算出来的 —— 是**用户要的**。
  2. **2 分钟是默认值，不是上限。** 默认值的意思是「你不说，我按这个来」；一旦装不下，正确的动作是**停下来说清楚要多久**，而不是自己删条、自己拉长。
  3. **删条 = 替用户改内容。** 为了塞进 2 分钟丢掉成稿里的条目，等于把上游三棒的判断在最后一步砍掉 —— 那一步不该由一个念稿子的人做。
- **如何从真推出：**
  ① 契约里把时长从「成稿的 ±10%」改成**默认 2 分钟**（默认值语义）；
  ② 装不下时**先报数再问**：「照现在的量大概要 X 分 Y 秒，你要加到多久」——加多久由用户定，契约里写死「不自己定时长」；
  ③ 「不加、不删」写进「我干什么」，堵住两条自救路（自己加开场 / 自己删条）；
  ④ 落盘那条从「先给人看，再落盘 / 没点头不许写文件」换成用户的原词 **「不点头，不落稿」**，并把断言同步换掉。

## 0. 用户价值（必填 · 站在用户角度）

- **谁用：** 拿到小宋成稿、想听一版口播稿的人。
- **解决什么痛点：** ① 旧口径 `±10%` 让口播稿的长度由**成稿**决定，成稿一长，口播就跟着长 —— 用户想要的是「2 分钟那一版」；② 稿子装不下时没有出路，写手要么偷偷删条、要么硬撑出一版念不完的稿；③ 落盘门槛用的是别人的词（「先给人看」），用户说的是「不点头，不落稿」。
- **用完后用户多得到什么：** 默认拿到 2 分钟那一版；量大的时候，**先被问一句**「要到多久」，由自己拍板；没点头之前，磁盘上不会多出一个文件。
- **好用性自检：**
  - [x] 不需要额外运行时 / 数据库
  - [x] 步骤可感知、可预期（默认 2 分钟 → 装不下问一句 → 贴全 → 等点头）
  - [x] 不增加无意义确认或噪音（只在**真装不下**时多问一次）
  - [x] 主操作一眼能找（贴全稿 + 一句「预计 X 分 Y 秒」）
  - [x] 高频路径更干净（不再需要用户自己算字数）

## 0b. 产品经理视角（必填 · 禁止跳过）

- **场景：** 小宋交稿 → 用户叫小雨出手 → 对话里出现「预计 X 分 Y 秒」+ 全篇口播稿 → 用户点头 → 落 `outputs/<日期>/口播稿-<日期>.md`。
- **怎么走完：**
  1. 小雨只读 `outputs/<日期>/成稿-<日期>.md`；
  2. 按 2 分钟出稿，写完**在对话里贴全**（是稿子本身，不是摘要、不是「已落盘」）；
  3. 若 2 分钟装不下：先停下说「照现在的量大概要 X 分 Y 秒」，**问用户加到多久**，用户给了数再写；
  4. 用户说「落」才写文件；说要改，改完**再贴一遍**再等。
- **看起来怎么样：** 一版能直接念的稿子 + 一行 `预计 X 分 Y 秒`；没有 `ID` / `秒槽` / `口径` / `索引` / `落盘` / `material_read` 这些内部词。
- **好走 / 好看：** 用户从「给一份稿」到「点头」只多一个动作 —— 量大的时候回一句时长。
- **成功标准：** 契约里搜不到 `±10%`；能搜到「默认 2 分钟」「装不下就停下来问」「加到多久」「不点头，不落稿」。
- **明确不做什么：** 不把 2 分钟写成硬上限；不许自己加开场 / 结尾段；不许为了塞进 2 分钟删条；不改原意；不伸手去读资讯 / 索引 / 选题单。

## 0c. 架构师视角（必填 · 禁止修修补补）

- **根因层级：** 契约层 —— 旧口径把口播稿长度**挂到成稿身上**（`±10%`），于是「多长」这件事没有了用户的位置；同时落盘断言钉的是旧词（`先给人看，再落盘` / `没点头不许写文件`），改词不改断言就会两头打架。
- **正确的长期默认路径：** 时长是**用户的输入**，不是稿子的推论 —— 默认 2 分钟、超出就问。契约里写清默认值与提问时机，写手不做取舍。
- **边界：** 只动小雨自己这一摊 —— 上游三棒（王海燕 / 吕老师 / 小宋）一字不动；小宋契约里那条「先给人看，再落盘」（写稿那一棒）**保留不动**，两棒各说各的产物。
- **如何落地：**
  - `crates/hermes-core/src/personas/xiao-yu.md` 0.3.0 → **0.4.0**：`empty_hint` 提默认 2 分钟；重写「我干什么」「不点头，不落稿」「我不干什么」「给用户的话」；删掉「口播化不改长度」「±10%」；
  - `crates/hermes-core/src/persona.rs`：小雨的钉子换成 `不点头，不落稿` / `默认 2 分钟` / `装不下就停下来问` / `加到多久` / `给用户的话`，并加一条**反着钉**（`!contains("±10%")`），把旧口径堵死。

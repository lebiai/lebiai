## 0-fp. 第一性原理

- **拒绝的类比：** 不是因为 Todoist / 系统提醒 / Notion / Claude Code 有 todo，所以也要有。仓库里已有的 `todo_write` 是当次草稿纸，不能冒充跨天承诺。也不是会议纪要抽全部 action，不是进化 reflection 抽规则。
- **拆出的真：**
  1. 主场是谋划与把事推进。人会在对话里拍板，拍板后没有跨会话、用户可审的落点。
  2. 记忆是一类事一条规则；技能是流程；会话是流水账；`todo_write` 会话一关就散。**承诺会蒸发。**
  3. 用户说的「提醒」≈ 待办：共事时把欠债递回来，不是闹钟。
  4. 搭子陪你做，不替你当项目经理。默认路径仍是对话。
  5. 说得多 ≠ 欠得多。在办只问「停下来还欠几件能单独交差的事」。
  6. 假阳性比漏一条更伤；离开是为了停，不能再考一次试。
  7. 近义是同一笔债，不是句子像；已完成不是合并对象。
- **如何从真推出：** 第四类明文对象「在办」；对话收 + 手建同一列表；离开只写「待收下」；提醒只在对话递回；侧栏次操作；不进「它记得的」、不进进化收件箱。做法、界面、确认见规格 §4–§7。

## 0. 用户价值

- **谁用：** 桌面 GUI 个人用户（默认路径）。CLI 调试可后接同一份数据。
- **痛点：** 聊完就散；同类事第二次还要重说「我还欠什么」。
- **用完后：** 欠的还在、下次开口能递回、排得动也砍得动；手感规则不被待办实例撑脏。
- **好用性自检：**
  - [x] 不需要数据库 / 中间件（一份本机明文）
  - [x] 主操作仍是说话；侧栏一眼能找
  - [x] 离开不新增弹窗噪音
  - [x] 空 / 载 / 错态在规格里写清
  - [x] 高频路径：一句话记下，或侧栏一行回车

## 0b. 产品经理视角

- **场景：** 桌面对话里拍板、手建一条、离开后下次再来、问今天干什么。
- **怎么走完：** 规格 §4。先看见对话；记下后侧栏出现原话；离开最多浅浅一条待收下；下次至多一句递回。
- **看起来怎么样：** 规格 §7。侧栏一块，不是第四顶栏、不是看板。空态一句话教「记下」。
- **好走 / 好看：** 手建一个框；确认切法一个主按钮；不与进化离开抢戏。
- **成功标准：** 规格 §11 用户语言清单。不靠人在旁边解释「在办不是待办 App」。
- **不做什么：** 规格 §10。

## 0c. 架构师视角

- **根因层级：** 缺领域对象。现有 session / memory / skill / inbox / `todo_write` 都不是「跨次还欠的交差」。
- **正确默认路径：**
  - 一份 `data_root()/commitments.json`（或同等明文），原子写。
  - 引擎工具在 `hermes-tools`（①），GUI 只是同一份数据的表面。
  - 离开余债独立扫描，禁止塞进 `ReflectionOutput`。
  - 系统提示只注入开着的标题（≤7），与技能同一套 Progressive Disclosure。
  - `todo_write` 保持会话隔离，不改语义。
- **入口边界：** v1 = GUI + 引擎。Server/Flutter 标计划中。IM 白名单不含写。身份协议只改 `companion.rs` 一小节，须与 P0 同词。
- **安全：** 无密钥；手建/勾完本地；对话抽取走授权门禁；无确认表面 fail-closed。
- **防复发：** 规格写死「三层不混」「离开 ≠ 立项」「近义先对开着的列表」。测试覆盖切法、离开 0/1 条、近义不误并已完成。
- **为何不是补丁：** 新对象一条默认路径，不是在记忆或 `TODOS.md` 上叠 if。
